# 桌面启动脚本（源文件）

这两个文件是**桌面快捷方式的源版本**，放在仓库里是为了别丢（换机器 / 重装时直接从这儿复制）。

| 文件 | 作用 |
|---|---|
| `启动酒馆RAG服务.cmd` | 启动服务（后台 uvicorn），并建立「自愈开关」`temp/service.enabled` |
| `停止酒馆RAG服务.cmd` | 删掉自愈开关 + 杀掉占用 8000 的进程 |

## 怎么用

**直接在本仓库里跑**：双击 `tools/desktop/` 下的这两个文件即可 —— 它们用 `%~dp0..\..` 自动定位项目根，换目录也能用。

**放到桌面**：把 `.cmd` 复制到桌面（或建快捷方式）也行。注意两点：

1. 如果复制到桌面，`%~dp0` 就变成桌面了 —— 简单起见**建快捷方式**（右键 → 发送到 → 桌面快捷方式），而不是复制文件本身。
2. 文件必须保持 **GBK 编码**（cmd 默认代码页 936）。用记事本改完保存时要选 ANSI，否则中文会变乱码、甚至影响脚本执行。

## 自愈开关是怎么回事

`temp/service.enabled` 是个空文件，含义是"**我想让服务跑着**"：

- 「启动」脚本创建它 → 探活脚本（`tools/watchdog.py`，由计划任务每 3 分钟跑一次）发现服务掉了会**自动把它拉回来**
- 「停止」脚本删掉它 → 探活脚本就什么都不做（**不会**把你刚停掉的服务偷偷复活）

**为什么要这个开关**：没有它的话，你手动关掉服务后会被自动拉起来 —— 想关都关不掉。
