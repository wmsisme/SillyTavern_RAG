
# 开发与自动化

SillyTavern 的默认包仅提供一个基础平台，可以通过多种方式进行扩展。

> **[STscript](/usage/st-script/)**
>
> STscript 是一种强大的脚本语言，基于批量聊天命令，无需任何编程基础即可上手。
> > **📝 提示**
>

**[函数调用](/for-contributors/function-calling/)**

通过让 LLM 使用外部数据源或触发扩展的特定功能，添加更多动态能力。
> **📝 提示**

> **[外部提供商集成](/for-contributors/provider-integrations/)**
>
> 在自定义 OpenAI 兼容设置、UI 扩展、服务器插件或官方集成的预先讨论之间进行选择。
> > **📝 提示**
>

**[UI 扩展](/for-contributors/writing-extensions/)**

UI 扩展在浏览器环境中运行，通过接入 SillyTavern 的事件和 API 来扩展其功能。
> **📝 提示**

> **[服务器插件](/for-contributors/server-plugins/)**
>
> 服务器插件允许通过在 NodeJS 环境中运行代码来添加新 API 端点等功能。
> > **📝 提示**
>

**[国际化 (i18n)](/for-contributors/i18n/)**

了解如何将 SillyTavern 的 UI 翻译成你的语言。
> **📝 提示**
