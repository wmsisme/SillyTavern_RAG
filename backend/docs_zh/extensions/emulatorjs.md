
# EmulatorJS

此扩展允许您直接在 SillyTavern 聊天中运行复古主机游戏。

## 安装方法

**前置条件：**

- 最新版本的 SillyTavern。
- 从网络下载的 ROM 文件。您可以在[任何地方](https://archive.org/details/ni-romsets)找到它们。

**如何安装：**

1. 使用 SillyTavern 的扩展下载器进行安装。
2. 或使用此链接：`https://github.com/SillyTavern/SillyTavern-EmulatorJS`

## 使用方法

- 打开“EmulatorJS”扩展菜单。
- 点击“添加 ROM 文件”。ROM 文件将保存在您的浏览器存储中，不会存储在服务器上。
- 选择要添加的游戏文件。输入游戏名称和核心（如果未自动检测到）。如果核心需要 BIOS 文件，也请一并添加。
- 点击列表中的“播放”按钮，或通过魔杖菜单启动。
- 启动游戏后，您可以在模拟器窗口中自定义控件和其他设置。
- 如需暂停休息，可使用保存/加载状态功能。

查看 EmulatorJS 文档以了解可用核心列表及其要求：[核心](https://emulatorjs.org/docs4devs/cores)

## 评论模式

借助多模态模型的强大功能，您的 AI 角色可以实时观看您的游戏画面并发表风趣幽默的角色扮演评论。

### 前提条件

1. 浏览器需支持 [ImageCapture](https://developer.mozilla.org/zh-CN/docs/Web/API/ImageCapture#browser_compatibility)。已在桌面版 Chrome 上测试。Firefox 需要在配置中启用此功能。Safari 无法使用。
2. 推荐使用支持内嵌图像的聊天完成 API。请查阅 API 文档以确认所选模型是否支持多模态提示。
3. 如果禁用了图像内嵌功能，请确保已启用 [图像描述](/extensions/captioning/#multimodal-source) 扩展，然后选择“多模态”描述来源。

### 如何启用评论

1. 确保在 EmulatorJS 扩展设置中设置了评论生成间隔。此设置决定了每隔多久基于当前游戏画面的截图向角色请求一次评论。值为 0 表示不生成评论。
2. 选择一个角色聊天并启动游戏。为获得最佳效果，请确保 ROM 文件名称正确，以便 AI 能获得更多背景上下文。
3. 像往常一样开始游戏。视觉模型将定期被调用来基于它“看到”的最新截图撰写一条评论。

### 设置

1. 描述模板 - 用于描述游戏截图的提示词。支持 `{{game}}` 和 `{{core}}` 附加宏。
2. 评论模板 - 用于基于生成的描述撰写评论的提示词。支持 `{{game}}`、`{{core}}`、`{{caption}}` 附加宏。在图像内嵌模式下，`{{caption}}` 会被替换为 `see included image`。
3. 强制描述 - 即使支持并启用了图像内嵌模式，也会强制使用多模态描述。

### 为什么我看不到任何评论？

如果满足以下条件，评论将暂时暂停（跳过间隔步骤）：

1. 模拟器处于暂停状态（使用暂停按钮，而非游戏内暂停）。
2. 浏览器窗口失去焦点。
3. 用户输入区域不为空。这是为了让您可以不受干扰地输入回复。
4. 当前正在进行另一个回复生成。
5. TTS 语音正在朗读。评论会等待（最多 30 秒）直到朗读结束，但不会被跳过。
6. 角色卡或群组当前处于打开状态。从欢迎屏幕启动游戏时，评论模式会被禁用。

其他常见问题：

1. 确保在启动游戏前已设置评论间隔。
2. 确保已设置多模态 API 密钥，并且 ST 服务器控制台中没有错误。

仍然无法工作？请向我们发送您的浏览器调试控制台日志（按 F12）。
