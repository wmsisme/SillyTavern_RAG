
# Blip

本指南将引导您为SillyTavern体验设置并自定义blip扩展。该扩展以可变速度对消息文本进行动画处理，并在动画过程中播放声音。您可以使用音频文件或生成声音。

## 前提条件

在开始之前，请确保您满足以下前提条件：

- 确保您使用的是最新版本的SillyTavern。
- 从扩展面板（堆叠方块图标）中的“下载扩展与资源”菜单安装“Blip”扩展。

## Blip全局设置

1. **Blip用户消息**：
   - 勾选复选框以在用户消息上播放动画。
   - 为用户设置一个配置文件，或者如果您希望用户使用blip动画，则设置一个默认配置文件。

2. **仅对特定文本启用Blip**：
   - 勾选复选框以仅对引号内的文本启用blip。
   - 勾选复选框以忽略星号内的所有内容。

3. **自动向下滚动**：
   - 勾选复选框以使聊天向下滚动以跟随文本动画，如果您希望在动画期间自由滚动，请取消勾选。

4. **音频音量**：
   - 如果只需要文本动画，请将音频静音。
   - 您可以调整blip音频的全局音量。

## 角色动画/语音配置文件

您可以为每个角色保存一个配置文件：
   - 包括用户和一个可选的默认配置文件，当角色没有配置文件时将使用该默认配置文件。
   - 如果列表中仅显示当前聊天角色，请勾选复选框以显示所有角色。

1. **选择要分配/更新配置文件的角色**：
   - 选择一个角色。如果该角色已有配置文件，则会被加载。
   - 如果该角色尚未有配置文件，则当前参数将成为其配置文件设置。
   - 可以使用移除按钮删除任何配置文件。
   - 如果您的角色未出现在列表中，请使用刷新按钮。

2. **文本动画设置**：
   - 设置文本速度：每个字母打印之间的延迟（毫秒）。
   - 将最小/最大速度乘数设置为不同于1.0的值，以实现速度动画的随机性。
   - 将逗号/短语延迟设置为大于0，以在打印特殊字符时添加暂停，这可以为动画增添更多生动感。在这种情况下，音频也会暂停。

3. **音频参数**：
   - 如果需要，设置一个仅影响该语音配置文件的音量乘数。
   - 设置音频速度：每个blip声音之间的延迟，独立于文本速度。

4. **Blip来源：生成的声音**：
   - 使用最小/最大频率滑块自定义播放的blip声音。
   - 如果最小值和最大值不同，则每次播放该范围内的随机声音。

5. **Blip来源：文件**：
   - 从列表中选择一个文件。
   - 您可以从资源扩展菜单中获取官方的ST blip资源。
   - 或者直接将文件放入：`\SillyTavern\data\<用户标识>\assets\blip`。
   - 如果需要，勾选复选框以强制等待整个文件播放完毕后再播放。
