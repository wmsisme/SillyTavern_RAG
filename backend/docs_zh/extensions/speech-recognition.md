
# 语音识别

本指南将引导您在 SillyTavern 中设置语音识别，将您的语音转录为文本。

## 前提条件

在开始之前，请确保您已满足以下前提条件：

- 确保您使用的是最新版本的 SillyTavern。
- 从扩展面板（堆叠方块图标）的“下载扩展与资源”菜单中安装“语音识别”扩展。

## 语音识别设置（浏览器）

1. **配置 SillyTavern**：
   - 启动 SillyTavern，进入 **扩展** > **语音识别**。
   - 从下拉选项中选择“浏览器”。
   - 如果您的浏览器不支持语音识别，将出现错误弹窗。

2. **选择消息模式**：
   - 选择您想要的“消息模式”：
     - **追加**：您的消息将追加到当前用户消息文本框。
     - **替换**：您的消息将替换文本框中的当前用户消息。
     - **自动发送**：一旦检测到语音结束，您的消息将自动发送。

3. **启用消息映射** *(可选)*：
   - 设置短语映射以实现语音快捷键。
   - 例如，添加“command delete = /del2”，当检测到“command delete”时，`/del2` 命令将替换您的语音消息。
   - 结合自动发送模式可实现完全语音控制，非常有用。勾选“启用消息映射”以启用此功能。

4. **选择语言**：
   - 选择您要说的语言（注意：并非所有浏览器都支持所有语言）。

5. **录音**：
   - 要开始录音，点击发送按钮旁边消息区域右侧的麦克风按钮。再次点击停止录音。如果未检测到语音，录音可能会自动停止。

## 语音识别设置（API 源）

支持 OpenAI、MistralAI、Groq、Chutes、Z.AI 以及其他提供语音转文本 API 的源。

设置方法：

1. 在聊天补全 API 设置中为所选提供商提供 API 密钥。
2. 启动 SillyTavern，进入 **扩展** > **语音识别**。
3. 从下拉选项中选择所需的 API 源。
4. 根据需要配置其他设置，与“浏览器”提供商设置类似。

## 语音识别设置（Extras） - 已弃用

> **📝 提示**
需要安装 ffmpeg 二进制文件。更多详情请参见 [RVC 设置](/extensions/rvc/#rvc-setup)。
> **📝 提示**

1. **启用提供商**：
   - 使用以下命令在 extras 服务器上启用所需的语音识别提供商：
     ```shell
     python server.py --enable-modules=whisper-stt
     ```
     或
     ```shell
     python server.py --enable-modules=vosk-stt
     ```
   - 您也可以通过添加选项 `--stt-vosk-model-path` 或 `--stt-whisper-model-path` 并指定模型路径来使用自定义模型。

2. **配置 SillyTavern**：
   - 启动 SillyTavern，进入 **扩展** > **语音识别**。
   - 从下拉选项中选择“Vosk”或“Whisper”（Whisper 更准确）。
   - 设置与“浏览器”提供商设置类似（语言除外），请参见上文。

## 语音识别设置（流式） - 已弃用

> **📝 提示**
需要安装 ffmpeg 二进制文件。更多详情请参见 [RVC 设置](/extensions/rvc/#rvc-setup)。
> **📝 提示**

1. **启用提供商**：
   - 使用以下命令在 Sillytavern-extras 上启用流式语音识别模块：
     ```shell
     python server.py --enable-modules=streaming-stt
     ```

2. **配置 SillyTavern**：
   - （可选）如上文 Whisper 设置中所述，指定自定义 Whisper 模型。
   - （可选但推荐）在 SillyTavern 中设置触发词。只有以这些触发词开头的消息才会作为实际消息发送到 SillyTavern。这可以防止随机语音或噪音被转录。通过复选框启用此功能。可以使用复选框选择是否在消息中包含/排除触发词。
   - 其他设置与其他提供商类似。

现在您已准备好在 SillyTavern 中使用语音识别将语音转录为文本。
