
# 正则表达式

## 这是什么？

正则表达式扩展允许用户自动检测文本字符串中的特定模式（称为“序列”）并对其应用操作（替换）。当与其他 SillyTavern 功能（如[快速回复或 STscript](/usage/st-script/)）结合使用时，它可以成为一个强大的工具，或者仅仅作为一种从聊天中移除特定词语的方式。

## 有用链接

**本文档不会深入解释编写正则表达式序列的过程。有许多在线资源可以帮助你完成这项工作。**

- [https://regexr.com](https://regexr.com)

- [https://regex101.com](https://regex101.com)

- [https://extendsclass.com/regex-tester.html](https://extendsclass.com/regex-tester.html)

- [https://en.wikipedia.org/wiki/Regular_expression](https://en.wikipedia.org/wiki/Regular_expression)

## 前提条件

正则表达式是 SillyTavern 的内置扩展，因此无需额外设置。

你可以在 **<i class="fa-solid fa-cubes"></i> 扩展** 面板中找到其设置。

## 常见用例

正则表达式通常用于对聊天中的特定词语应用查找替换功能，为特定词语或句子类型添加 Markdown 样式，或向 STscript 返回布尔值。

## 脚本列表

![正则表达式扩展脚本列表](/static/extensions/regex-listview.png)

- 顶部的按钮用于创建新脚本。
  - “全局”脚本将应用于所有角色，并保存到 `settings.json` 中。
  - “范围”脚本仅应用于当前活跃的角色，并保存到角色卡的数据中。
- “导入”允许你导入从另一个 SillyTavern 实例导出的正则表达式脚本。

下方是你的脚本列表，附带一些操作按钮。

- 拖动手柄（脚本名称左侧的三条横线）允许你拖放脚本，按任意顺序排列。
- 主开关可以快速切换以启用或禁用脚本，而无需更改其他任何设置。禁用的脚本会以~~删除线~~样式显示。**如果脚本在此处被禁用，它将无法被快速回复或 STscript 触发。**
- “编辑”（铅笔）按钮将打开正则表达式脚本编辑器。
- “移至范围”（向下箭头）将把全局脚本转换为范围脚本并应用于当前角色。反过来（向上箭头），它会将范围脚本转换为全局脚本。
- “导出”将导致你的浏览器下载脚本的 `.json` 导出文件，然后可以将其分享并导入到另一个 SillyTavern 实例中。
- “删除”（垃圾桶）删除该脚本。

## 正则表达式编辑器

![正则表达式编辑器](/static/extensions/regex-editor.png)

- **测试模式**：这将在编辑器顶部打开一个对比视图。在“输入”框中输入一些文本，你的正则表达式脚本的结果将显示在输出框中。这是一个有价值的调试工具，因为当你更改脚本设置时，它会实时更新输出框。

- **名称**：扩展脚本列表中显示的脚本标签。**这也用于在通过斜杠命令或 STscript 触发脚本时定位该脚本。**

- **查找正则表达式**：这是用于检测目标文本模式的正则表达式。这通常是任何正则表达式脚本中最复杂的部分，也是最容易出错的地方。请参阅页面顶部的链接，了解如何编写正则表达式序列。如果“查找正则表达式中的宏”设置为允许（见下文），此框可以解析[常见 SillyTavern 宏](/usage/core-concepts/macros/)的值（如 \{\{user\}\}、\{\{char\}\} 等）。

- **替换为**：这是将替换匹配序列的内容。在一个非常简单的例子中，如果你的“查找正则表达式”是 `apple`，而你的“替换为”是 `orange`，那么在应用脚本的任何文本中，第一个出现的“apple”将自动变为“orange”。

  - 在此框中添加扩展特定的宏 \{\{match\}\} 将插入完整的匹配文本序列。这通常用于为特定词语应用样式。回到上面的例子，如果将 \*\*\{\{match\}\}\*\* 放入“替换为”框中，所有出现的“apple”将被替换为 `**apple**`，这将为其应用粗体 Markdown 样式。

  - 诸如 $1、$2、$3 等变量可用于插入所谓的“捕获组”。这些是“查找正则表达式”序列匹配的文本序列中的子字符串。**请注意，使用这些变量要求匹配表达式包含括号组，以定义匹配字符串的哪部分算作捕获组。** 请参阅顶部链接以了解如何设置捕获组。

- **修剪掉**：放入此框中的文本将在应用“替换为”过程之前从匹配的文本序列中移除。例如，如果我们的匹配是“apple”，而修剪掉框中包含“le”，那么在应用“替换为”过程之前，字母“le”将首先被移除。由于我们的“替换为”框包含 \*\*\{\{match\}\}\*\*，结果将是 `**app**` 被作为“apple”的替换内容（首先移除“le”，剩余的匹配文本被赋予粗体 Markdown 样式）。可以通过在要移除的每个字符串之间添加换行来应用多个修剪。

- **影响范围**：此复选框列表定义了正则表达式脚本将应用于哪些文本来源。
  - “用户输入”：脚本将在用户点击发送后对其输入的文本内容运行。
  - “AI 回复”：脚本将在收到 AI 回复后对其内容运行。
  - “斜杠命令”：脚本将对斜杠命令插入到提示/聊天中的值运行。
  - “世界信息”：脚本将在世界信息条目注入提示时对其内容运行。**需要勾选“修改传出提示”（或取消勾选两个临时性复选框）。**
  - “推理”：脚本将对 Chat Completion API（如 Gemini 或 Deepseek）返回的“推理”对象内容运行。如果在临时性下勾选了“修改传出提示”，脚本还将应用于后续聊天轮次中添加到提示的任何推理块。
  - **如果此处全部未勾选，脚本在正常聊天期间将永远不会激活，但仍可通过斜杠命令或 STscript 激活。**

- **其他选项**：
  - “禁用”阻止脚本运行。这用作一种覆盖手段，当你只是不想更改脚本的任何设置和/或不想通过脚本列表上的开关完全禁用它时（因为这样做会阻止斜杠命令触发它），可以用它来阻止脚本运行。
  - “编辑时运行”使脚本在聊天消息被编辑后也运行。如果未勾选此项，编辑后的聊天消息内容将不会触发脚本。

- **查找正则表达式中的宏**：选择是否替换“查找正则表达式”框序列中存在的宏（如 \{\{user\}\}、\{\{char\}\} 等）。
  - “不替换”将导致任何 SillyTavern 宏被忽略，因此正则表达式脚本在搜索时会将其视为字面文本。
  - “原始”将逐字发送宏的值。如果宏的值包含某些特殊字符，这可能会改变正则表达式脚本搜索文本的方式。
  - “转义”将在每个字符前添加正则表达式转义斜杠 `\`，以确保它们不会意外改变整个正则表达式序列。如果宏的值中包含某些特殊字符，这可能很有用。

### 深度设置

最小/最大深度设置提供了对正则表达式模式将影响聊天历史中哪些消息的精确控制：

- **最小深度**：仅影响聊天历史中至少 N 层深的消息
  - 0 = 最后一条消息
  - 1 = 倒数第二条消息
  - 以此类推。
  - 当留空（设置为“无限制”）或为 -1 时，也会影响继续操作时要继续的消息

- **最大深度**：仅影响聊天历史中不超过 N 层的消息
  - 必须大于最小深度，正则表达式才会生效
  - 系统提示和实用提示不受这些设置影响

例如，将最小深度设置为 0，最大深度设置为 2，将只对你的正则表达式应用于聊天中最近的三条消息。

### 标志

默认情况下，查找正则表达式模式区分大小写，并且仅应用于第一个匹配项。要调整此行为以及其他正则表达式标志，你可以像这样添加它们：

```txt
/yourpattern/flags
```

示例：`/yourpattern/gi` 将匹配文本中所有出现的“yourpattern”，无论大小写。

一些最常见的标志是：

- `i`：不区分大小写
- `g`：全局（应用于所有匹配项，而不仅仅是第一个）
- `s`：dotAll（将输入视为单行，因此 `.` 将匹配换行符）
- `m`：多行（将输入视为多行，因此 `^` 和 `$` 匹配每行的开头/结尾，而不仅仅是整个字符串）
- `u`：Unicode（将输入视为 Unicode，因此 `\d`、`\w` 等将匹配 Unicode 字符）

有关正则表达式标志的更多信息，请参阅以下 MDN 页面：[使用标志进行高级搜索](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide/Regular_expressions#advanced_searching_with_flags)

### 临时性

默认情况下（当此处两个框都未勾选时），正则表达式脚本将直接编辑存储在聊天 JSONL 文件中的文本值。这确保传出提示和聊天显示始终包含相同的值。但是，对聊天文件的这些更改是不可逆的。

如果你不希望发生这种情况，可以启用此处的任一复选框，将正则表达式脚本的影响限制为仅显示或仅传出提示。

如果只勾选了其中一个框，则不会对聊天文件进行任何更改，但**只有勾选的项目**会被更改。这意味着你看到的内容和 LLM 看到的内容将不同。请谨慎使用。

如果两者都被选中，脚本将在所有方面正常运行，唯一不同的是它不会将任何更改写入聊天文件。

## 高级用法

虽然正则表达式通常用作简单的查找/替换工具，但它也可以以更复杂的方式使用。

例如，“替换为”框可以包含一组 CSS 规则和 HTML，以便在找到某个特定词语时向你的聊天中添加一个特定样式的 HTML 元素。这需要在用户设置面板中取消勾选 `在回复中显示 <tags>` 框。

脚本也可以设置为在正常使用期间永不触发，而是通过斜杠命令作为 STscript 中逻辑检查的一部分来触发。“替换为”框将包含脚本识别的唯一值，以指示逻辑检查为真还是假。这将正则表达式的实用性扩展到所有斜杠命令的全部能力，允许基于聊天内容实现真正无限级别的控制和自动化。
