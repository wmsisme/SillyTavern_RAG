
# 角色表情

## 这是什么？

表情图片是你的 AI 角色的图片（也称为“精灵图”），会显示在聊天窗口旁边（或后面）。

表情图片可以根据分类自动变化，以适应 AI 最新聊天回复中所表达的情绪。

## 添加角色表情图片

1. 打开扩展面板并展开“角色表情”部分。如果你已打开角色聊天，你会看到一个图片占位网格。
   ![表情抽屉](/static/extensions/expression-drawer.png)
2. 点击网格中每张图片左上角的“上传图片”按钮，并选择你想要应用于该情绪的图像。这将把图像以正确的文件名保存到 `/data/<用户句柄>/characters/(角色名)/` 文件夹中。
3. 对所有你想要指定图像的表情重复此操作。

### 导入表情图片 ZIP 文件

使用“<i class="fa-solid fa-file-zipper"></i> 上传精灵包 (ZIP)”按钮，你可以导入一个包含多张表情图片的 zip 文件，这些图片将自动被添加到**当前选中角色**的正确文件夹中。ZIP 文件必须将所有图片以扁平结构（无子文件夹）且文件名正确的方式包含在内。导入 zip 文件不会自动重命名任何图片以匹配情绪。

## 手动切换表情

1. 点击任意已上传的表情图片（精灵图），即可在聊天界面附近（默认 UI 模式）或屏幕中央（视觉小说模式）显示。
2. 使用 `/expression-set (名称)` 斜杠命令或匹配的快速回复来设置精灵图，而无需打开扩展菜单。

## 自动切换表情

若要在角色回复时自动设置表情，你有多种选择。
当启用消息流式传输时，表情会按每一条消息或在固定间隔变化。

### 分类模块如何工作？

`classify` 模块使用一个与 SillyTavern 服务器一起运行的小型“情感解析”模型。该模型接收 AI 的新输出，并检测文本所表达的情感或情绪类型。虽然一条消息中可能包含多种情绪，但模型只选取最可能的一种并返回给 SillyTavern。然后前端扩展会显示与该情绪关联的图像。

### 设置指南（本地）

1. 打开扩展面板并展开“角色表情”扩展菜单。
2. 在分类源下拉菜单中选择“本地”。
3. 这将开始从 HuggingFace Hub 一次性下载分类模型（约 100 MB）。
4. 生成任意一条消息以验证分类是否正常工作以及精灵图是否出现。你也可以查看服务器控制台中的调试日志。

本地分类默认支持 28 个可能的图像标签：[Cohee/distilbert-base-uncased-go-emotions-onnx](https://huggingface.co/Cohee/distilbert-base-uncased-go-emotions-onnx)

若要使用 6 选项分类模型，请将 `config.yaml` 文件中的 `extensions.models.classification` 变量值更改为：[Cohee/bert-base-uncased-emotion-onnx](https://huggingface.co/Cohee/bert-base-uncased-emotion-onnx)

### 设置指南（使用 LLM）

1. 通过 **<i class="fa-solid fa-plug"></i> API 连接** 连接到任何一个受支持且正确配置的 API。
2. 按照上述方式导入表情图片。
3. 在分类源下拉菜单中选择“主 API”。
4. （可选）配置分类指令提示词。
5. 生成任意一条消息以验证分类是否正常工作以及精灵图是否出现。你也可以查看服务器控制台中的调试日志。

#### 提示构建策略

主 LLM 源允许选择如何构建分类提示词：

* **有限上下文**：仅发送最后一条消息和系统指令提示词。
* **完整上下文**：发送整个聊天历史，包括角色卡。

### 设置指南（WebLLM）

1. 安装官方的 [WebLLM 扩展](https://github.com/SillyTavern/Extension-WebLLM)。
2. 按照上述方式导入表情图片。
3. 在分类源下拉菜单中选择“WebLLM”。
4. （可选）配置分类指令提示词。
5. 生成任意一条消息以验证分类是否正常工作以及精灵图是否出现。你也可以查看服务器控制台中的调试日志。

### 设置指南（使用 Extras）

> [!WARNING]  
> Extras 已弃用，可能在未来的更新中移除。

1. 确保已安装并运行 Extras，并启用了 `classify` 模块：`python server.py --enable-modules=classify`
2. 按照上述方式导入表情图片。
3. 在分类源下拉菜单中选择“Extras”。
4. 每当 AI 向你发送回复时，相应的表情图片将自动显示。

Extras API 默认使用一个包含 6 个选项的分类模型：[nateraw/bert-base-uncased-emotion](https://huggingface.co/nateraw/bert-base-uncased-emotion)

还有一个包含 28 个选项的模型：[joeddav/distilbert-base-uncased-go-emotions-student](https://huggingface.co/joeddav/distilbert-base-uncased-go-emotions-student)

若要使用此模型，你需要在 Extras 命令行中添加以下参数（前后各有一个空格）：`--classification-model=joeddav/distilbert-base-uncased-go-emotions-student`

## 自定义表情

如何获得比默认更多的表情选项？你可以在扩展设置中设置**自定义表情**。你可以为自定义表情指定任意名称。它们将出现在表情图片列表中，并且可以像其他表情一样分配图片。它们会有一个指示符表明是自定义的。

> [!TIP]
> 本地和 Extras 都只支持有限的表情列表。
>
> 如果你希望显示自定义表情，则需要训练一个带有支持标签的分类模型（超出本指南范围），或者你可以使用 LLM 或 WebLLM 作为分类源，这两者都会自动使用所有现有的表情——包括默认表情和任何自定义表情。

## 表情支持哪些图片格式？

任何图片格式都允许，包括 webp 和动图。

最常见的格式是带有透明背景的 PNG 文件。

## 使用默认表情

如果你没有某个角色的全部表情图片，或者完全没有图片，你有多种默认显示选项。
所有这些都可以通过“默认/后备表情”下的下拉菜单选择。

1. **选择后备表情**：当选中的表情没有对应的图片时，将显示后备表情。只需从下拉菜单中选择一个可用的表情即可。
2. **[无后备]**: 当没有图片时，不显示任何内容。
3. **[默认表情]**: 你可以使用 SillyTavern 内置的默认表情。这些是简单的表情符号风格图片。

## 每个表情使用多张图片

可以为每个表情添加多张图片，以增加显示表情的多样性。  
要启用此功能，只需切换**允许每个表情使用多个精灵图**。  
现在你可以上传多张图片，额外的图片将带有一个小标记。

单个图片可以通过点击手动选择，或者使用 `/expression-set type=sprite` 命令，该命令会列出可用的精灵图图片，而不是表情。

当自动选中一个包含多张图片的表情时，将从现有图片中随机选择一张。  
如果你希望在同一个表情被多次使用时强制选择该表情的新图片，可以启用**如果再次使用相同精灵图则重新选择**。

### 每个表情多张图片的命名规则

当每个表情包含多张图片时，文件需要按特定方式命名。
文件名必须以表情名称开头，后跟一个后缀，用点号或短横线分隔。例如：`joy.png`、`joy-1.png`、`joy.expressive.png`  
无论是直接上传还是 ZIP 导入，文件名都必须遵循此格式。

## 精灵文件夹覆盖

> [!NOTE]
> 显示名称（而非角色卡文件名）决定了使用哪一组图片集合

如果你有多个显示名称相同的角色，它们将使用同一组表情图片。

如果你希望为同名角色的每个版本使用不同的图片集，可以使用精灵文件夹覆盖功能。  
文件夹覆盖也可用于定义同一角色的不同精灵集（服装等）。

### 如何设置覆盖

1. 在 `/data/<用户句柄>/characters` 下创建一个任意名称的文件夹，并将图片放入其中，例如 `/data/<用户句柄>/characters/Boris`。
2. 打开你想覆盖精灵图的角色的聊天。
3. 在“精灵文件夹覆盖”输入框中输入覆盖文件夹的名称，然后点击“提交”。
4. 精灵图列表将重新加载，“精灵集”指示符应显示覆盖文件夹。
5. 或者，你可以使用 `/costume` 斜杠命令达到相同效果：`/costume Boris`。
6. 如果在覆盖文件夹名称前加上反斜杠，它将解析为当前角色精灵文件夹的子文件夹，例如，对于名为 Boris 的角色，`/costume \tracksuit` 将解析为 `/data/<用户句柄>/characters/Boris/tracksuit` 文件夹。
