
# Mancer

Mancer 是一个大型语言模型推理服务，允许您运行任意提示，且不会审查回复。大多数模型需要预充值余额才能开始对话，但在撰写本文时（2024-11-28）存在一个免费模型。

- [模型](https://mancer.tech/models)
- [定价](https://mancer.tech/pricing)

## 如何开始

1. 在 [mancer.tech](https://mancer.tech/) 注册一个账号。
2. 点击“仪表盘”（Dashboard）并复制您的 API 密钥。

    ![截至 2024-02-27 的 Mancer 仪表盘](/static/mancer-dashboard.png)

3. 在 SillyTavern 中，选择“文本补全 API”（Text Completion API），然后在“API 类型”（API Type）下选择 Mancer。
4. 输入您的 Mancer API 密钥并点击“连接”（Connect）。

![API 密钥](/static/mancer-key.png)

现在您应该可以与您选择的任何 Mancer 模型进行聊天了。

## 匿名日志记录

如果您不介意您的聊天内容可能被用于训练模型、改进 Mancer 服务、发布数据集或 *其他任何* 他们决定做的事情，您可以选择启用匿名日志记录，以获得选定模型的 25% Token 折扣。只需前往您的 [Mancer 仪表盘](https://mancer.tech/dashboard.html)，勾选“启用匿名日志记录”（Enable Anon. Logging）即可。
