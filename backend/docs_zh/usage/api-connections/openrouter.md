
# OpenRouter

> **ℹ️ Info**
>
> OpenRouter 既可作为文本补全源，也可作为聊天补全源使用。所有模型均可通过任一 API 访问，但其功能可能因您选择的 API 类型而异。例如，图像内联和工具调用仅适用于聊天补全 API。


不想注册十几个 API 服务，但仍想访问所有最新模型？使用 OpenRouter。

OpenRouter 让您通过一个端点即可访问 DeepSeek、Claude 和 Gemini 等模型，所有模型均在同一服务中，共享一个信用池。

它提供免费试用（约 1 美元），之后需付费使用。无需订阅或月费——您只需为实际使用的部分付费。部分模型提供免费访问，但每日请求次数有限。

> **💡 Tip**
>
> 要永久获得具有慷慨每日限制的免费模型访问权限，您需要**一次性**购买至少 10 美元的信用额度。
>
> 更多详情请参阅 [OpenRouter FAQ 页面](https://openrouter.ai/docs/faq)。


- 创建 OpenRouter 账户：[openrouter.ai](https://openrouter.ai/)
- [OpenRouter 模型列表](https://openrouter.ai/models?order=pricing-low-to-high)

![OpenRouter-连接面板](/static/openrouter-connection.png)

从上到下（见上图）：

1. 选择“聊天补全”API。
2. 选择 OpenRouter 作为来源。
3. 点击“授权”通过 OAuth 流程获取密钥。或者，在[此处](https://openrouter.ai/keys)生成 API 密钥并粘贴到框中。
4. 点击“连接”并选择一个模型。
5. （可选）使用“测试消息”按钮验证您的连接。
