
# 聊天文件管理

本页面介绍管理 AI 聊天文件的各种方式。

> **ℹ️ 注意**
>
> 部分选项可通过左下角选项菜单中的“管理聊天文件”对话框使用。


## 单人聊天 vs 群组聊天

使用角色卡的最简单方式是单人聊天：只需点击角色卡即可开始聊天。

当你拥有多张角色卡后，还可以使用“创建新聊天群组”按钮创建包含多个角色的[群组聊天](/usage/core-concepts/groupchats/)，这些角色将与你及彼此之间进行互动。

## 聊天导入

**将 Character.AI 的聊天记录导入 SillyTavern。**

若要导入 Character.AI 的聊天记录和机器人，请使用 CAI Tools 浏览器扩展：[https://github.com/irsat000/CAI-Tools](https://github.com/irsat000/CAI-Tools)。

其他可从中导入聊天记录的程序和工具包括：

* TavernAI（原始版）：<https://github.com/TavernAI/TavernAI>
* Text Generation WebUI（oobabooga）：<https://github.com/oobabooga/text-generation-webui>
* Agnai：<https://github.com/agnaistic/agnai>
* KoboldAI Lite：<https://github.com/LostRuins/lite.koboldai.net>
* RisuAI：<https://github.com/kwaroran/RisuAI>

## 导出为 .jsonl

点击“管理聊天文件”时，聊天文件列表中的每个条目都会有一个导出按钮，可以将其导出为可原样重新导入的格式。使用此功能可分享或迁移聊天记录及其所有元数据（但不包含图片和文件附件）。

如果你注重隐私，请务必检查导出的 JSONL 文件，并擦除任何你不想分享的内容。

## 导出为 .txt

你也可以使用“将聊天记录下载为纯文本文档”按钮导出简化的纯文本版本。该版本无法重新导入，因为会丢失重要的元数据！

## 检查点

“检查点”是当前聊天的克隆，它们会复制从给定聊天开始到特定时间点的所有消息，并存储一个指向源聊天（按聊天文件名）的链接。

通过每条聊天消息右侧的三点按钮，你可以用两种方式创建检查点：

* “创建分支”会将当前聊天复制到该消息处并切换到该分支
* “创建检查点”会将当前聊天复制到该消息处，要求输入名称并创建，但不会切换到该检查点

你可以大致将其理解为浏览器中的“在新标签页中打开链接”和“在后台新标签页中打开链接”。

从检查点返回父聊天时，可以点击消息文本框左侧的汉堡菜单按钮，然后点击“返回父聊天”。

## 重命名聊天

默认情况下，聊天文件以创建时的日期和时间命名。

你可以通过点击铅笔图标并输入新名称来更改。

请注意，这会导致检查点中指向该聊天的链接失效（因为它们是通过聊天文件名关联的）。
