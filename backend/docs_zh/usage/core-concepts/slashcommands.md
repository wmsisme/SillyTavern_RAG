
# 斜杠命令

> **⚠️ Warning**
>
> **此列表并非详尽无遗，因为更新频率较低。**
>
> 如需获取在当前实例中可用的最新命令列表，请在任意 SillyTavern 聊天窗口中使用 `/help slash` 聊天命令。


- `/help` – 显示帮助信息
- `/api` - 切换到不同的 API
- `/sys` - 以系统叙述者身份发送一条中性消息
- `/send` - 以用户身份发送消息，但不触发生成
- `/sendas` – 以特定角色身份发送消息
- `/comment` - 在聊天中添加一条对 AI 不可见的注释
- `/impersonate` - 请求 AI 以你的身份撰写，可附带提示语
- `/persona` - 设置你的用户角色
- `/imagine` - 根据文本提示生成图像
- `/bg` - 按文件名设置背景图片
