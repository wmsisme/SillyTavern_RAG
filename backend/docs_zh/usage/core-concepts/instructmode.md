
# 指令模式

指令模式允许你针对基于各种提示格式（如 Alpaca、ChatML、Llama2 等）训练出的指令跟随模型调整提示方式。

> **📝 适用于：文本补全 API**
>
> 对于聊天补全 API 中的等效设置，请使用[提示管理器](/usage/prompts/prompt-manager/)。


## API 支持

### 文本补全 API

完全支持。包括：

* 文本补全下的所有来源
* KoboldAI Classic
* AI Horde

#### 选择格式

所选的指令模板必须与后端运行的实际模型的预期格式相匹配。

这通常反映在 HuggingFace 上的模型卡片中，有些甚至还提供了与 SillyTavern 兼容的 JSON 文件。

示例：[NeverSleep/Noromaid-13b-v0.1.1](https://huggingface.co/NeverSleep/Noromaid-13b-v0.1.1#prompt-template-custom-format-or-alpaca)

### 聊天补全 API（OpenAI、Claude 等）

聊天补全 API **不支持（也无需支持）** 此模式。它们使用完全不同的提示构建器。

### NovelAI

虽然从*技术上*支持 NovelAI，但其模型均未经过指令格式训练。NovelAI 模型可以使用一个特殊的指令模块，当聊天消息中遇到花括号包裹的指令时，该模块会*自动激活*，因此对整个提示使用指令模式会导致输出质量**下降**。

以下是一个自动激活 NovelAI 指令模块的示例：

```txt
User: { Write a happy song about Nintendo Switch. }
```

## 指令模式设置

### 系统提示

> **⚠️ 最近变更**
>
> 系统提示现在是一个独立实体。详情请参阅[高级格式设置](/usage/core-concepts/advancedformatting/#system-prompt)页面。


### 模板

提供了一些知名指令模型的即用模板，包含序列。

*更改模板会将未保存的设置重置为上次保存的状态！如果进行了任何不想丢失的更改，请务必保存你的模板。*

### 激活正则表达式

如果定义为一个有效的正则表达式，当连接到模型且模型名称与此正则表达式匹配时，将自动选择此模板。

需要预先启用指令模式。模板中仅会匹配第一个正则表达式（按字母顺序评估）。

### 序列换行包裹

每个序列文本在插入提示时会被换行符包裹。Alpaca 及其衍生模型需要此项。

如果需要完全控制换行符，请禁用此选项。

### 序列中的宏替换

如果启用，在消息包裹序列中定义的已知 \{\{macro\}\} 替换将被执行。

此外，可以在消息前缀中使用特殊的 \{\{name\}\} 宏来引用消息关联的实际名称（而非当前活跃的 \{\{char\}\} 或 \{\{user\}\}），这在群聊或使用 /sendas 命令时很有帮助。如果无法确定名称，则使用 "System" 作为回退占位符。

### 包含名称

如果启用，在前缀序列之后，将角色名称和用户名称添加到聊天历史日志前。

可用选项：

* **从不**：不在消息内容前添加名称前缀。
* **群组和过往角色**：仅对群组角色和过往角色的消息添加名称前缀。
* **始终**：始终在消息内容前添加名称前缀。

### 序列：故事字符串包裹

> **⚠️ 最近变更**
>
> 系统提示包裹已被移除，替换为故事字符串包裹。


定义当位置设置为“默认（上下文顶部）”时，故事字符串如何被包裹。

#### 故事字符串前缀

在故事字符串之前插入。

#### 故事字符串后缀

在故事字符串之后插入。

### 序列：聊天消息包裹

这些设置定义了在构建提示时，不同角色的消息应如何被包裹。

所有前缀序列也将自动用作停止字符串。

#### 用户消息前缀

在用户消息之前插入，并在模拟用户时作为提示最后一行。

#### 用户消息后缀

在用户消息之后插入。

#### 助手消息前缀

在助手消息之前插入，并在生成 AI 回复时作为提示最后一行。

#### 助手消息后缀

在助手消息之后插入。

#### 系统消息前缀

在系统消息（由斜杠命令或扩展添加）之前插入。

#### 系统消息后缀

在系统消息之后插入。

#### 系统同用户

如果勾选为 true，系统消息将使用用户角色的消息序列。

否则，系统消息将使用其自身的序列（如果不为空），或者完全不进行任何包裹（如果为空）。

### 其他序列

用于更精细调整提示构建的各种高级配置。

#### 首条助手前缀

在第一条助手消息之前插入。

> **ℹ️ Info**
>
> 仅计算**聊天历史**中的第一条消息，而非实际最先进入提示的消息！


#### 最后助手前缀

在最后一条助手消息之前插入，或在生成 AI 回复时作为提示最后一行。

> **ℹ️ Info**
>
> 在后台生成文本（例如 Stable Diffusion 提示或摘要）时不使用。将使用系统指令前缀或常规助手前缀代替。


#### 系统指令前缀

在后台生成中性/系统文本（例如 Stable Diffusion 提示或摘要）时作为提示最后一行插入。

#### 用户填充消息

如果聊天历史不以用户消息开头，则会在其开头插入此消息。

**使用场景：** 当指令格式*严格要求*提示以用户开头且消息角色必须交替出现时，例如 Llama 2 Chat、Mistral Instruct。

#### 停止序列

表示回复结束的文本。也会作为停止字符串发送给后端 API。

如果生成了停止序列，则输出中该序列之后的所有内容（包括序列本身）将被移除。
