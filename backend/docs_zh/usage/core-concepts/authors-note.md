
# 作者备注

## 这是什么？

作者备注是一个用于自定义AI响应的强大工具，它可以将一段文本插入到提示词中的任意位置，并按照你想要的任何频率进行插入。

## 使用方法

作者备注可以在聊天输入栏左侧的“选项”菜单中找到。

## 配置作者备注

### 聊天专属作者备注

作者备注面板顶部的文本框包含当前聊天的作者备注。

**此文本框中的内容不会自动转移到任何新聊天中。**

### 放置选项

#### 场景之后

此选项将作者备注放在上下文顶部，位于角色定义的“场景”部分之后。如果没有指定场景，则将其放在角色定义的最后部分之后、示例消息之前。

#### 在聊天中

此选项将作者备注插入到聊天历史中的指定深度。

深度0 = 放置在聊天历史的最末尾。

深度4 = 放置在最近3条聊天历史消息之前，使其成为聊天历史中的第4个实体。

_作者备注越靠近提示词的末尾，对下一个AI响应的影响就越大。_

### 插入频率

这是你希望作者备注包含在聊天中的频率。

频率0 = 作者备注永远不会被插入。

频率1 = 作者备注将在每次用户输入提示词时被插入。

频率4 = 作者备注将每隔4次用户输入提示词被插入一次。

### 默认作者备注

面板底部的文本框包含默认作者备注，该备注将应用于每个新聊天。

## 常见用例

### 提醒AI响应格式

作者备注可用于指定AI应如何撰写其响应。

- [你的下一个响应长度必须为300个token。]
- [以埃德加·爱伦·坡的风格写下你的下一个回复。]
- [使用Markdown斜体表示未说出的动作，使用引号指定说出的词语。]

### 强化指令

- [请记住本聊天开始时给你的指令。]

### 作为临时世界信息、角色偏好或非指令模型的指令

- [\{\{char\}\} 在图书馆里]
- [\{\{user\}\} 腿上有一道新伤，所以无法逃跑。]
- [\{\{char\}\} 无法说话，必须用手势交流。]
