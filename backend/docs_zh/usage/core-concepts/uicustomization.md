
# 界面自定义

## 界面主题

### 主题管理

主题文件允许您保存、共享和重用界面自定义设置。您可以针对不同心情或用途维护多个主题，并在它们之间即时切换。

* 导入/导出主题文件
* 删除现有主题
* 保存对当前主题的更改
* 另存为新主题

本节中的所有设置都会保存到当前主题。如果切换主题，这些设置将被新主题的设置所取代。

### 显示设置

这些显示选项影响角色和消息在聊天界面中的呈现方式。

#### 头像样式

在圆形、正方形、矩形或圆角正方形之间选择。此设置同时适用于用户和 AI 的头像。

#### 聊天样式

| 样式         | 描述                                                                                                                                    | [斜杠命令](/usage/st-script/#ui-styling) |
|--------------|---------------------------------------------------------------------------------------------------------------------------------------|-------------------------------------------------------|
| **扁平**     | 干净且连贯的“聊天记录”风格，为您的 AI 交互提供平坦的画布。                                                                             | `/flat`<br>`/default`                                 |
| **气泡**     | “即时通讯”风格，每条消息都有独特的气泡、讨喜的圆角和微妙的 3D 效果。                                                                  | `/bubble`<br>`/bubbles`                               |
| **文档**     | 紧凑、类似文档的外观，以文本为中心。隐藏过往消息的头像、时间戳和消息控制按钮。                                                        | `/single`<br>`/story`                                 |

### 通知

设置通知弹出（Toast 消息）在屏幕上出现的位置。

* 左上角
* 顶部居中（默认）
* 右上角
* 左下角
* 底部居中
* 右下角

### 媒体样式

聊天消息中媒体附件（图片、音频、视频）的默认显示样式。向聊天消息追加媒体的扩展可能会覆盖此设置。也可以在每条消息中通过消息上下文菜单中的“切换媒体显示样式”操作手动更改。

* **列表**：以网格状布局一次性显示所有媒体附件。
* **画廊**：以轮播式画廊显示媒体附件。

> **📝 提示**
此设置也会影响内联媒体附件如何发送给支持的聊天补全源：列表会一次性发送所有附件，而画廊则只发送选中的附件。
> **📝 提示**

### 主题颜色

自定义每个界面元素的配色方案，打造完美主题。可以使用颜色选择器选取颜色，并在适用情况下包含透明度选项。

* 主文本
* 斜体文本
* 下划线文本
* 引用文本
* 文本阴影
* 聊天背景
* 界面背景
* 界面边框
* 用户消息
* AI 消息

### 布局与视觉设置

使用这些滑块微调界面的视觉效果。

* **聊天宽度**：调整聊天窗口宽度（屏幕宽度的 25-100%）
* **字体缩放**：自定义文本大小（0.5-1.5 倍）
* **模糊强度**：控制界面面板模糊（0-30）
* **阴影宽度**：调整文本阴影强度（0-5）

### 主题开关

这些开关控制各种界面功能和行为。某些选项可以在低端设备上提升性能，另一些则为聊天界面添加有用的信息或功能。

* **减少动效**：禁用动画和过渡效果
* **无模糊效果**：移除背景模糊以提升性能
* **无文本阴影**：禁用文本阴影效果
* **[视觉小说模式](/usage/user-settings/visual-novel/)**：带背景精灵的紧凑聊天界面
* **展开消息操作**：始终显示完整的消息上下文菜单
* **极简滑块**：简化参数控件
* **疯狂实验室模式**：取消参数范围限制
* **消息计时**：显示 AI 响应生成时间
* **聊天时间戳**：显示消息时间戳
* **模型图标**：显示 AI 模型的消息图标
* **消息 ID**：显示消息顺序编号
* **隐藏聊天头像**：从聊天中移除头像
* **消息 Token 计数**：显示每条消息的 Token 数量
* **紧凑输入区**：单行输入（仅移动端）
* **全部消息显示滑动编号**：在所有消息上显示滑动编号
* **角色快速切换**：快速选择收藏角色的按钮
* **头像悬停放大**：鼠标悬停头像时的缩放效果
* **标签作为文件夹**：使用标签作为文件夹来组织角色
* **点击编辑**：点击消息快速打开编辑器

### 自定义 CSS

允许您应用自定义 CSS 样式以进一步定制聊天界面的外观。

使用 <i class="fa-fw fa-solid fa-maximize" title="展开图标"></i> **展开** 展开编辑器窗口以获得更好的可视性和编辑体验。

如果切换主题，您的自定义 CSS 将被新主题的自定义 CSS 替换。若想在切换主题时保留自定义 CSS，请确保将其保存到某个主题中。

如果使用了大量自定义 CSS，或希望在不同主题间使用相同的自定义 CSS，非官方的 [CSS Snippets 扩展](https://github.com/LenAnderson/SillyTavern-CssSnippets) 可以帮助您管理和组织自定义 CSS。

## 消息音效

要在收到机器人新消息时播放自定义音效，请替换 SillyTavern 文件夹中的以下 MP3 文件：

`public/sounds/message.mp3`

以 80% 音量播放。

如果启用了“[仅后台音效](/usage/user-settings/#杂项)”，则仅在 SillyTavern 窗口**未聚焦**时才会播放音效。

## 公式渲染

要启用数学公式渲染，请使用 [LaTeX 扩展](https://github.com/SillyTavern/Extension-LaTeX)。要获取该扩展，需要通过 SillyTavern 中的“下载扩展与资源”菜单进行安装。

在代码块中使用 `latex` 或 `asciimath` 语言标识符分别编写 LaTeX 和 AsciiMath 公式。该扩展使用 [KaTeX](https://katex.org/) 进行渲染。

<pre><code>```latex
\int_{-\infty}^{\infty} e^{-x^2} dx = \sqrt{\pi}
```

```asciimath
int_{-oo}^{oo} e^{-x^2} dx = sqrt{pi}
```</code></pre>

> **ℹ️ 弃用通知**
>
> 旧的 `$` 和 `$$` 包裹语法已不再支持。请使用以下正则表达式脚本对旧语法进行 polyfill：
>
> * [$$ - LaTeX](https://github.com/SillyTavern/Extension-LaTeX/raw/refs/heads/main/assets/$$_-_latex.json)
> * [$ - AsciiMath](https://github.com/SillyTavern/Extension-LaTeX/raw/refs/heads/main/assets/$_-_asciimath.json)
