
# 标签

角色卡和群组可以分配零个或多个标签。它们有助于按主题、质量、来源或任何你喜欢的标准来组织快速增长的角色集合。

## 标记

有多种方法可以为角色卡添加或移除标签：

- 在导入时导入嵌入的标签。
- 从角色管理面板中打开一张卡片。在此处你可以为角色卡分配标签。
- 批量标记。

要进行批量标记，点击“批量编辑角色”按钮（铅笔图标），选择你想要标记的卡片，右键点击其中任意一张，然后在上下文菜单中选择“标签”。

> **ℹ️ 注意**
>
> 请注意，群组无法进行批量标记。


在此界面中，你将能够：

- 使用组合框添加或移除标签。
- 移除所选卡片上的所有标签（“全部”）。
- 移除所选卡片中所有卡片共有的标签交集（“共有”）。
- 导入（在本地创建）角色卡中存储的所有标签（如果你导入的角色卡中包含标签）（“导入全部”）。
- 导入（在本地创建）角色卡中存储且本地也存在同名匹配的标签（“导入已有”）。

## 管理

要查看和管理所有现有标签，打开角色管理面板，然后点击“管理标签”按钮（齿轮图标）。

你可以使用右上角的按钮备份和恢复此处的所有信息（标签列表、标签与卡片的关联、颜色、文件夹设置等）。

你可以使用左侧的拖拽按钮重新排序标签，排序结果将反映在角色管理面板的标签过滤器中。

> **⚠️ 警告**
>
> 标签备份的 JSON 文件不打算与他人共享，因为它包含仅适用于你实例的特定信息，例如内部实体名称！


## 导入角色卡时导入标签

当从下载的图片（或通过“从外部 URL 导入内容”按钮）导入外部角色卡时，系统会提示你选择是否导入角色卡中包含的标签。这些标签对卡片功能并非必需；它们仅用于组织管理。

嵌入的卡片标签存储在角色编辑器的“高级定义”菜单中的“创作者元数据”部分。如果你希望向将导入该角色的其他用户推荐一些标签，请在“待嵌入标签”字段中填入以逗号分隔的标签列表。

> **ℹ️ 注意**
>
> 此弹窗仅当用户设置中的“导入卡片标签”选项设置为“询问”时才会出现。


在打开的“为角色名称导入标签”弹窗中，你将看到一个现有标签列表（本地已有同名标签的项）和一个新标签列表（本地没有的项）。

你可以：

- 根据需要修剪列表，然后点击“导入”——剩余的现有标签将添加到导入的角色卡中，剩余的新标签将在本地创建并添加到角色卡中。
- 或者直接点击“不导入”以忽略角色卡中包含的标签，仅导入卡片本身。
- 或者点击“导入全部”作为快捷方式，导入角色卡中找到的所有标签（注意：此操作会包括你在上述列表中修剪掉的任何标签；如果你进行了修剪，请使用“导入”按钮）。
- 或者点击“导入已有”作为快捷方式，仅导入本地已有同名匹配的标签。

## 过滤角色卡

创建标签后，它们会显示在角色管理面板的一行中。你可以点击这些标签来切换标签过滤状态；顺序如下：

- 一次点击：显示带有此标签的卡片。
- 再次点击：仅显示不带有此标签的卡片。
- 再次点击：重置对此标签的过滤。

你可以同时按任意数量的标签进行过滤。

## 标签作为文件夹

> **ℹ️ 注意**
>
> 要使用此功能，需先在用户设置中的“UI 主题”列下启用它。此开关的状态也会随 UI 主题一起保存。


在“管理标签”按钮（齿轮图标）中，每个标签条目都有一个多状态切换按钮，可以在以下标签作为文件夹的模式之间循环（代码中称为“虚拟文件夹”）：

- 一次点击：将此标签变为“打开的文件夹”。它将作为虚拟条目出现在卡片列表中；点击进入将仅显示带有该标签的卡片。
- 再次点击：将此标签变为“关闭的文件夹”。同上，但带有此标签的卡片默认不会显示——你需要点击进入文件夹才能看到它们。
- 再次点击：重置此标签的“标签作为文件夹”状态。
