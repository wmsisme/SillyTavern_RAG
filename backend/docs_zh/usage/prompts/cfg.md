
# CFG

贡献者：kingbri, Guillaume "Vermeille" Sanchez, AliCat

## 这是什么？

CFG（无分类器引导，classifier-free guidance）是一种用于帮助使提示词的某些部分更不突出或更突出的方法。

### 支持的后端 API

目前，支持的后端有 oobabooga 的 textgen WebUI、NovelAI 和 TabbyAPI。
NovelAI 有其自己的 [CFG 文档](https://web.archive.org/web/20240917150051/https://docs.novelai.net/text/cfg.html)。

警告：CFG 会因需要处理多于一个提示词而增加 VRAM 使用量！如果在开启 CFG 生成提示词时 GPU 内存耗尽，请考虑减小上下文大小、使用参数更少的模型，或者完全关闭 CFG。

## 配置

访问 CFG 设置的方式与访问作者注释相同：

![CFG 汉堡菜单](/static/cfg-hamburger.png)

以下是 CFG 面板的样式：

![CFG 聊天面板](/static/cfg-panel.png)

CFG 面板中有四个下拉菜单：

- 聊天 CFG
  
  - 将 CFG 缩放比例和提示词限定为仅当前聊天
- 角色 CFG
  
  - 将 CFG 缩放比例和提示词限定为指定角色
- 全局 CFG
  
  - 全局覆盖 CFG 缩放比例和提示词（也会覆盖模型预设！）
- CFG 高级设置（原名 CFG 提示级联）
  
  - 用于合并前三个下拉菜单中的提示词并设置插入深度。

注意：如果引导缩放比例设为 1，则不会发送任何内容，因为此时 CFG 处于“关闭”状态。

#### 群组聊天

在群组聊天中，CFG 缩放面板如下所示：

![CFG 群组面板](/static/cfg-groups.png)

主要变化是角色 CFG 被移除，并在聊天 CFG 下拉菜单中出现了一个名为“使用角色 CFG 缩放比例”的复选框。这使得可以使用当前角色的引导缩放比例，而不是聊天 CFG 中设定的比例。

此功能的主要用途是根据每个角色的个体需求调整缩放比例。

此外，在提示级联中勾选“角色负面提示”复选框，会将独立的角色负面提示词与聊天中的负面提示词（如果启用）一并附加。

## 概念

### 这不就是 Stable Diffusion 里的东西吗？

既是也不是。LLM 中的 CFG 工作方式与在 Stable Diffusion 中人们所习惯的方式不同。基于 LLM 的 CFG 遵循“提示混合”原则。CFG 公式接收一个正面提示词和一个负面提示词，然后混合它们之间的*差异*。接着，一个合并后的提示词被发送，并生成响应！

以下图示有助于可视化这一概念。红色代表负面提示词，蓝色代表中性提示词，紫色代表最终解释的混合结果。所有三个提示词中的空白区域相同，因此这些区域不用于 CFG 混合。

![CFG 图示](/static/cfg-diagram.png)

### 我需要 CFG 提示词吗？

不需要！CFG 提示词完全是可选的。仅仅将引导缩放比例调整到 `1` 以上也会对响应产生效果，这可以增强聊天和角色互动的表现力。

### 什么是好的 CFG 提示词？

我们已经确定，CFG 提示词与 Stable Diffusion 的负面标签和嵌入并不相同。那么如何构建一个提示词呢？

警告：以下内容假设你已经使用 PLists 和 Ali:Chat 创建了一个角色。如果没有，请随意尝试各种提示技术。

假设我有一个角色叫“约翰”。根据他的示例对话，约翰应该总是感到快乐和兴奋。然而，在与约翰聊天时，他有时会显得悲伤和沮丧。

为了消除这种情况，CFG 来帮忙了！只需将负面提示词设为 `[约翰的感受：悲伤、沮丧]`，即可帮助移除悲伤部分。你还可以选择性将正面提示词设为 `[约翰的感受：快乐、愉悦]`，以进一步突出约翰快乐的部分。

### 正面提示词

我在上一节中已经提到过这一点，但我想再深入谈谈。正面提示词用于进一步突出角色中的某些部分。再次以约翰为例。通过使用正面提示词 `[约翰的感受：快乐、愉悦]` 让他更快乐，约翰输出的对话应该会比未包含正面提示词时更具愉悦感。

### 但是...

这些只是基于特定角色格式的经验总结出的**粗略指导**。有很多其他创建提示词的方法，值得你去尝试。欢迎与其他用户分享你的想法！

### 引导缩放比例

这里有一条经验法则：引导缩放比例为 `1` 表示 CFG 已禁用。实际上，如果引导缩放比例为 1，SillyTavern 不会向后端发送任何内容。引导缩放比例 `>1` 会以不同程度产生其他章节所示的结果。

然而，引导缩放比例 `<1` 会产生*相反*的效果，因为此时负面提示词被用作主要提示词。

再次使用约翰的例子。负面提示词为 `[约翰的感受：悲伤、沮丧]`，正面提示词为 `[约翰的感受：快乐、愉悦]`，引导缩放比例为 `0.8`。

这反过来会更多地强调*负面*提示词，你会看到约翰开始表现得比平时更悲伤，而不是更快乐。

TL;DR：使用引导缩放比例 `1.5`，然后根据输出结果向上或向下调整。

### 提示级联

负面和正面提示词可以在 CFG 类型之间级联（类型包括按聊天、按角色和全局覆盖）。更多信息请参见“配置”标题。

### 插入深度

遵循基本规则：提示词中位置越低的内容，对响应的影响力越大。对于聊天，我建议使用默认深度 `1`，因为它与 SillyTavern 的其他组件非常灵活兼容。

然而，如果你想尝试，可以放心使用插入深度 `0`。但这可能会极大地改变响应的表现，**不建议**在此处使用提示级联！
