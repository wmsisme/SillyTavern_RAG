
# 提示词管理器

提示词管理器是一个系统，用于对聊天补全 API 的[提示词构建](/usage/prompts/)策略提供更多控制。

> **📝 适用于：聊天补全 API**
>
> 如需在文本补全 API 中设置等效选项，请使用[高级格式设置](/usage/core-concepts/advancedformatting/)。


> **💡 命名预设**
>
> 如果某个预设与你的角色卡名称相同，则在开始与该角色对话时会自动选中该预设。为避免此行为，请为预设取一个独特的名称。


通过点击导航栏中的“AI 响应配置”按钮访问提示词管理器。提示词管理器位于[通用设置](/usage/common-settings/)面板下方。

## 快速提示词编辑

提供快速编辑常用提示词部分的空间，例如**主提示词**、**辅助提示词**和**历史后指令**。有关这些提示词的更多信息，请参阅[提示词构建](/usage/prompts/)页面。

## 实用提示词

这些提示词被发送给聊天补全模型，以帮助其理解发送给它的信息，或指示其在某些类型的交互中以特定方式行动。

### 格式模板

> **💡 Tip**
>
> 如果未设置格式模板，信息将原样发送，不进行任何包裹。


这些是用于包裹从[世界信息](/usage/core-concepts/worldinfo/)和[角色卡](/usage/core-concepts/characterdesign/)中提取的信息的字符串模板。

使用一个特殊标记来指示信息应插入的位置：

- `{0}` 用于世界信息格式模板。
- `{{scenario}}` 用于场景格式模板。
- `{{personality}}` 用于性格格式模板。

### 群组提示模板

仅用于群组聊天。放置在提示词末尾，以强制特定角色回复。

留空可禁用群组提示功能。

### 新聊天、新群组聊天、新示例聊天

这些内容在聊天历史之前以及每个[示例对话](/usage/core-concepts/characterdesign/#对话示例)块之前发送，以告知模型背景信息在哪里结束，聊天历史从哪里开始。

- **新聊天：** 用于单人聊天。
- **新群组聊天：** 用于群组聊天。
- **新示例聊天：** 用于示例对话块。

留空可禁用此功能。

### 继续提示

在提示词末尾发送，指示模型在触发继续操作时应执行的操作，例如按下“继续”按钮或由 STScript 触发时。

> **📝 聊天补全“继续”**
>
> 请注意，聊天补全模型处理“继续”的方式与**文本补全**模型不同，无论你的继续提示如何，可能并不总能获得无缝的结果。


### 替换空白消息

当文本框为空且按下**发送消息**时，发送此字段的内容而非空白消息。

## 角色名称行为

提供不同策略，用于指示模型如何将消息与角色关联。如果聊天补全模型难以确定哪些消息属于哪个角色，可能需要选择不同的策略。

## 继续后缀

当触发继续操作时，模型返回的“继续”消息开头会添加选定的继续后缀。例如，可以在继续文本前添加一个空格。

## 附加设置

### 包裹在引号中

> **⚠️ Warning**
>
> 已弃用的选项。建议改用[正则脚本](/extensions/regex/)。


在发送前将整个用户消息包裹在隐藏的引号中。对于角色不使用引号表示对话的会话，此功能很有用。如果你的会话使用引号表示对话，请取消勾选此项。

### 继续预填充

> **⚠️ Warning**
>
> 可能不适用于所有聊天补全来源。


将继续提示作为助手角色消息而非系统消息发送。如果启用此选项，将不会使用继续提示。

### 合并系统消息

> **⚠️ Warning**
>
> 已弃用的选项。建议改用[提示词后处理](/usage/api-connections/openai/#提示词后处理)。


将连续的多个系统消息合并为一条组合消息（不包括示例对话）。

### 启用网络搜索

> **📝 提示**
不要与[网络搜索扩展](/extensions/websearch/)混淆。
> **📝 提示**

启用由聊天补全后端提供的网络搜索功能。提示词通常会被模型提供商添加搜索结果，并可能产生额外费用。

### 启用函数调用

请参阅[函数调用](/for-contributors/function-calling/)

### 发送内联图片、发送内联视频

> **📝 提示**
不要与[图像描述扩展](/extensions/captioning/)混淆。
> **📝 提示**

如果聊天补全模型具备处理提交图片和视频的多模态能力，此选项用于切换该能力。如需向提示词附加媒体，请使用“魔法棒”菜单中的**附加文件**选项。

### 请求内联图片

> **📝 提示**
不要与[图像生成扩展](/extensions/stable-diffusion/)混淆。
> **📝 提示**

允许模型返回图片附件。

### 使用系统提示

> **📝 提示**
仅受 Google Gemini 和 Anthropic Claude 后端支持。

尽管这两个后端的设置非常相似，但它们在技术上是独立的选项，因此可以分别配置。
> **📝 提示**

将所有系统消息合并，直到第一条非系统角色（用户/助手）消息为止，并将其作为单独的系统指令字段发送。

## “提示词”

提示词管理器构成了发送给聊天补全模型的提示词的主干。它控制发送的内容以及发送的*顺序*。

### “提示词”下拉菜单

包含当前聊天补全预设中所有（非默认）提示词的下拉列表。要将其中一个提示词添加到输出消息中，需要从下拉列表中选择它，然后按**插入提示词**按钮将其添加到提示词管理器中。要创建新提示词并添加到下拉列表中，请按**新建提示词**按钮。编写并保存新提示词后，它会添加到下拉列表中，随后即可插入。

### 提示词列表

这是一个拖放界面，列出了选中后可能发送给聊天补全模型的提示词。越靠近界面**顶部**的提示词发送得越早。列表**底部**是发送给模型的**最后内容**（通常是你设置的**历史后指令**）。

> **📝 “固定”提示词 = 默认提示词**
>
> 默认提示词无法从选中提示词列表中移除。这包括主提示词、世界信息（前/后）、角色描述、角色描述、角色性格、场景、增强定义、辅助提示词、聊天示例、聊天历史和历史后指令。如果不需要这些提示词，可以将其**切换为“关闭”**，但不能直接移除或删除。


## 编辑提示词

点击提示词上的**铅笔按钮**将进入**编辑界面**。在这里，你可以直接编辑提示词。

> **📝 确保保存更改！**
>
> 要永久保存对这些提示词的更改到你的聊天补全预设中，你必须点击**编辑界面**右下角的**保存**按钮，同时还要使用**AI 响应配置**部分顶部的**保存**按钮来保存预设本身！否则，当切换到其他聊天补全预设时，所做的更改将丢失。


### 名称

提示词的名称。此名称不会发送给聊天补全模型，仅用于提示词管理器中的参考。

### 角色

发送提示词的角色。可选择系统、AI 助手或用户。

### 触发器

该提示词被发送的生成类型。如果未选择任何项，则提示词将针对所有生成类型发送。如果选择了一项或多项，则提示词仅针对这些特定的生成类型发送：

- **正常：** 常规消息生成请求。
- **继续：** 按下“继续”按钮时。
- **扮演：** 按下“扮演”按钮时。
- **滑动：** 通过滑动触发生成时。
- **重新生成：** 在单人聊天中按下“重新生成”按钮时。
- **静默：** 后台生成请求，通常由[扩展](/extensions/)或 [STscript](/usage/st-script/) 命令触发。

> **📝 提示**
“重新生成”触发器在群组聊天中不可用，因为群组聊天使用不同的重新生成逻辑：会删除最后一次回复的所有消息，并根据所选的[群组回复策略](/usage/core-concepts/groupchats/#回复顺序策略)使用“正常”生成类型对消息进行排队。
> **📝 提示**

### 位置

当位置设置为**相对**时，此提示词将按照它在拖放界面中与其他提示词的顺序发送。当位置设置为**聊天内**并给定**深度**时，它会作为所选角色**插入到聊天历史中**，并且**忽略**拖放界面中的顺序。

### 深度

当位置设置为**聊天内**时，此设置定义提示词在聊天历史中插入的深度。数字越大，插入得越深。例如，深度为 0 将插入到最后一条聊天消息之后，深度为 1 将插入到最后一条聊天消息之前，深度为 2 将插入到倒数第二条聊天消息之前，依此类推。

### 顺序

> **📝 提示**
具有相同角色和深度的提示词会被分组在一起，并按其顺序值排序。
顺序如下（从上到下）：用户、AI 助手、系统。
> **📝 提示**

当位置设置为**聊天内**时，此设置定义提示词在聊天历史中发送的顺序。数字越小，发送得越早。
