
# 快捷键

**要获取当前 SillyTavern 实例中可用的最新快捷键列表，请在任意聊天中使用 `/help hotkeys` 斜杠命令。**

**移动设备上禁用快捷键。**

## 聊天快捷键

* 上箭头 = 编辑聊天中的最后一条消息
* Ctrl+上箭头 = 编辑聊天中的最后一条用户消息
* 左箭头 = 左滑
* 右箭头 = 右滑（注意：当聊天栏中有输入内容时，滑动快捷键被禁用）
* Enter（选中聊天栏时）= 将你的消息发送给 AI
* Ctrl+Enter = 重新生成上一条 AI 回复
* Alt+Enter = 继续上一条 AI 回复
* Escape
  * *（正在编辑消息且启用消息编辑自动保存时）* = 关闭编辑框。
  * *（当 AI 消息正在生成或流式输出时）* = 立即停止生成。

## Markdown 快捷键

需在“用户设置”选项卡中启用。适用于聊天栏和带有“M↓”图标的文本区域：

* Ctrl+B = \*\*加粗\*\*
* Ctrl+I = \*斜体\*
* Ctrl+U = \_\_下划线\_\_
* Ctrl+K = \`行内代码\`
* Ctrl+Shift+~ = \~\~删除线\~\~
