
# 欢迎页面助手

SillyTavern 具有一个欢迎界面，可以用指定的“助手”角色向您问好。当您启动 SillyTavern 但没有活跃的聊天，或者关闭最后一个聊天会话后，该界面会出现。

> **📝 注意**
>
> 如果在启动应用时没有看到欢迎界面，请确保在 **<i class="fa-solid fa-user-cog"></i> 用户设置** 面板的“聊天/消息处理”部分中，“自动加载最后一个聊天”选项已禁用。如果启用此选项，SillyTavern 将自动加载您的最后一个聊天，而不是显示欢迎界面。


## 欢迎界面

当没有活跃的聊天时，欢迎界面会提供几个有用的元素：

* **SillyTavern 版本：** 显示应用程序的徽标和当前版本。
* **快速链接：** 方便访问：
  * **文档：** 打开官方 SillyTavern 文档（您现在就在这里！）。
  * **GitHub：** 带您访问 SillyTavern GitHub 仓库（<https://github.com/SillyTavern/SillyTavern>）。
  * **Discord：** 提供官方 SillyTavern Discord 服务器的链接（<https://discord.gg/sillytavern>）。
* **临时聊天按钮：** 允许您快速开始一个新的临时聊天会话，与默认的中立助手进行对话，该会话除非您明确保存，否则不会保存到聊天历史中。
* **最近聊天部分：** 列出您最近的对话以便快速访问。您可以：
  * 显示或隐藏此部分。
  * 如果聊天数量超过 3 个（最多 15 个最近聊天），可以展开列表。

## 临时聊天

> **📝 注意**
>
> 由于技术限制，临时聊天功能不会使用您自定义的欢迎页面助手。它始终会开始一个空白聊天，不带任何额外的提示或角色信息。


临时聊天按钮允许您快速开始一个新的聊天会话，而不会将其保存到聊天历史中。这对于测试或随意对话很有用，而不会使您保存的聊天变得杂乱。一旦您关闭该聊天或切换到另一个聊天，此聊天将被删除。

* **保存** 按钮允许您将临时聊天导出为 JSONL 文件，以后可以再导入。
* **加载** 按钮允许您恢复之前保存的临时聊天文件。

## 什么是欢迎页面助手？

欢迎页面助手是您选择在欢迎界面上展示的角色。这可以实现个性化的问候，并让您从一开始就能快速与熟悉的角色开始聊天。

### 设置与取消设置助手

您可以选择任意角色作为您的欢迎页面助手。

**设置助手：**

1. 导航到 **角色管理** 面板（通常通过 <i class="fa-solid fa-address-card"></i> 图标从右侧边栏找到）。
2. 在列表中找到您希望设置为助手的角色。
3. 点击“更多...”，然后从下拉菜单中选择 **“设置/取消设置为欢迎页面助手”**。
4. 一个小的图标（<i class="fa-solid fa-user-graduate"></i>）将出现在该角色名称旁边，表示它现在是您的活跃欢迎页面助手。

**取消设置助手：**

1. 前往角色管理面板。
2. 找到您当前的欢迎页面助手（它将带有 <i class="fa-solid fa-user-graduate"></i> 图标）。
3. 再次点击“更多...”，然后选择 **“设置/取消设置为欢迎页面助手”**。
4. 该角色将不再是您的助手，<i class="fa-solid fa-user-graduate"></i> 图标将消失。
5. SillyTavern 将恢复使用默认助手（见下文）。

### 与助手互动

当欢迎界面显示了您选择的助手后，只需在屏幕底部的聊天输入栏中输入您的消息，然后按回车或点击发送按钮即可。这将开始一个新的与您的欢迎页面助手的聊天会话。

要打开与该助手的之前聊天，请使用最近聊天部分，或者在 **管理聊天文件** 对话框（通过 **<i class="fa-solid fa-bars"></i> 选项** 菜单访问）中找到该聊天。

## 默认助手

当您第一次与欢迎界面互动时，SillyTavern 会自动创建一个名为“助手”的默认角色。如果您没有将特定角色设置为您的欢迎页面助手，该角色将作为备用选项。

默认助手没有任何附加的特定提示，您可以自由地对其进行自定义（例如重命名、添加图片或设置个性）。

* 如果您没有明确地设置角色作为欢迎页面助手，则会使用这个默认助手。
* 如果您取消设置您选择的助手，系统将恢复使用此默认助手。
* 如果您设置为助手的角色被删除，系统也会恢复使用默认助手。

**注意：** 您不能像取消设置自己选择的角色那样“取消设置”默认的系统助手。要从默认助手切换，您必须将其他某个角色设置为助手。
