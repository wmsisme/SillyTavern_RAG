
# 通用设置

这些设置控制使用语言模型生成文本时的采样过程。这些设置的含义对于所有支持的推理后端都是通用的。

## 上下文设置

### 回复（词元数）

API 生成回复时使用的最大词元数量。

- 回复长度越长，生成回复所需时间就越长。
- 如果 API 支持，你可以启用 `流式输出` 以在生成过程中逐段显示回复。
- 当 `流式输出` 关闭时，回复将在完成后一次性显示。

### 上下文（词元数）

SillyTavern 作为提示词发送给 API 的最大词元数量，减去回复长度。

- 上下文包含角色信息、系统提示词、聊天历史等。
- 消息之间的虚线表示聊天的上下文范围。该线上方的消息不会发送给 AI。
- 要查看生成消息后的上下文组成，请点击 `提示词明细` 消息选项（展开 `...` 菜单并点击带线条的方形图标）。

## 采样器参数

### 温度

温度控制词元选择的随机性：

- 低温（<1.0）导致文本更具可预测性，倾向于选择高概率词元。
- 高温（>1.0）通过给予低概率词元更高机会，增加输出的创造性和多样性。

设置为 1 以使用原始概率。

### 重复惩罚

通过根据词元在上下文中出现的频率对其进行惩罚，来抑制重复。

将该值设置为 1 以禁用其效果。

#### 重复惩罚范围

从最后一个生成的词元开始向前多少个词元会被考虑用于重复惩罚。如果设置过高，可能会破坏回复，因为诸如 "the, a, and" 等常见词会受到最严重的惩罚。

将该值设置为 0 以禁用其效果。

#### 重复惩罚斜率

如果该值与 `重复惩罚范围` 均大于 0，则重复惩罚在提示词末尾的效果更强。值越高，效果越强。

将该值设置为 0 以禁用其效果。

### Top K

Top K 设置可供选择的最大顶级词元数量。例如，如果 Top K 为 20，则仅保留排名前 20 的词元（无论其概率是多样还是有限）。

设置为 0（或 -1，取决于你的后端）以禁用。

### Top P

Top P（也称为核心采样）累加所需的顶级词元，直到达到目标百分比。如果前两个词元的概率均为 25%，而 Top P 为 0.50，则仅考虑前两个词元。

将该值设置为 1 以禁用其效果。

### Typical P

Typical P 采样根据词元与集合平均熵的偏差对其进行优先排序。它保留累积概率接近预定义阈值（例如 0.5）的词元，强调具有平均信息量的词元。

将该值设置为 1 以禁用其效果。

### Min P

通过剔除相对于顶级词元概率较低的低概率词元来限制词元池。能产生更连贯的回复，但如果设置过高也可能加剧重复问题。

- 在 `0.1-0.01` 等低值时效果最佳，但在高 `温度` 下可设置更高。例如：`温度: 5, Min P: 0.5`

将该值设置为 0 以禁用其效果。

### Top A

Top A 根据最高词元概率的平方设置词元选择阈值。例如，如果 Top-A 值为 0.2，且顶级词元的概率为 50%，则概率低于 5%（0.2 * 0.5^2）的词元将被排除。

将该值设置为 0 以禁用其效果。

### Tail Free Sampling

无尾采样（TFS）通过使用导数分析词元概率的变化率，在分布中搜索低概率词元的尾部。它基于归一化二阶导数保留达到某个阈值（例如 0.3）的词元。值越接近 0，丢弃的词元越多。

将该值设置为 1 以禁用其效果。

### 平滑因子

通过二次变换提高高概率词元的可能性，同时降低低概率词元的可能性。旨在无论 `温度` 如何都能产生更具创造性的回复。

- 在没有 `Top K`、`Top P`、`Min P` 等截断采样器时效果最佳。

将该值设置为 0 以禁用其效果。

### 动态温度

根据顶级词元的可能性动态缩放温度。旨在在不牺牲连贯性的情况下产生更具创造性的输出。

- 接受从最小值到最大值的温度范围。例如：`最小温度: 0.75` 和 `最大温度: 1.25`
- `指数` 基于顶级词元应用指数曲线。

取消勾选以禁用其效果。

### Epsilon 截断

Epsilon 截断设置一个概率下限，低于该下限的词元将被排除在采样之外。单位为 1e-4；合理值为 3。

设置为 0 以禁用。

### Eta 截断

Eta 截断是特殊 Eta 采样技术的主要参数。单位为 1e-4；合理值为 3。详情请参阅论文 [Truncation Sampling as Language Model Desmoothing by Hewitt et al. (2022)](https://arxiv.org/abs/2210.15191)。

设置为 0 以禁用。

### DRY 重复惩罚

DRY 会惩罚那些会扩展输入末尾形成之前已在输入中出现过的序列的词元。如果你希望允许逐字重复某些序列（例如名称），可以将其添加到序列中断器列表中。请参阅 Pull Request [这里](https://github.com/oobabooga/text-generation-webui/pull/5677)。

将乘数设置为 0 以禁用。

### 排除顶级选择（XTC）

XTC 采样算法移除最可能的词元，而不是修剪最不可能的词元。它以给定概率移除除满足给定阈值的最不可能词元外的所有词元。这确保至少保留一个“可行”选择，从而保持连贯性。请参阅 Pull Request [这里](https://github.com/oobabooga/text-generation-webui/pull/6335)。

将概率设置为 0 以禁用。

### Mirostat

Mirostat 使输出的困惑度与输入的困惑度相匹配，从而避免重复陷阱（自回归推理生成文本时，输出困惑度趋于零）和混淆陷阱（困惑度发散）。详情请参阅论文 [Mirostat: A Neural Text Decoding Algorithm that Directly Controls Perplexity by Basu et al. (2020)](https://arxiv.org/abs/2007.14966)。

模式选择 Mirostat 版本。

- 0 = 禁用，
- 1 = Mirostat 1.0（仅限 llama.cpp），
- 2 = Mirostat 2.0。

### Beam Search

一种贪婪的蛮力算法，用于 LLM 采样中寻找最可能的词元序列。它一次性扩展多个候选序列，在每一步保持固定数量（束宽）的顶级序列。

### Top nsigma

一种基于统计特性过滤 logits 的采样方法。它保留在最大 logit 值的 n 个标准差范围内的词元，为 top-p/top-k 采样提供了一种更简单的替代方案，同时在不同温度下保持采样稳定性。
