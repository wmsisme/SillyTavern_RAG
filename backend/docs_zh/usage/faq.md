
# 常见问题

## 解释 SillyTavern 是什么

现代 AI 语言模型（如 ChatGPT）已经变得非常强大，其中一些能够令人信服地模拟你创建的角色，你可以与之聊天、共同创作小说等等。例如，你可以告诉 AI 假装成一位名叫 Jubei 的中世纪日本围棋教练，它会据此行动和回应。你可以与 Jubei 进行长时间聊天，一起去酒吧，决定与武士打架，无论你能想象到什么，AI 都会配合并围绕这些内容进行写作/反应，充当你的衬托和地下城主。你的想象力就是极限。你可以告诉 AI 假装它是神奇女侠。你还可以指定一个场景（“我和神奇女侠正在抢劫银行”）、一种写作风格（“神奇女侠用黑人英语说话”）或任何你能想到的其他内容。

SillyTavern 是一个促进这些用途的应用：

*   它是一个用户界面，负责与 AI 语言模型进行通信。
*   它允许你创建新的角色卡（提示），并在它们之间轻松切换。
*   它允许你导入其他用户创建的角色。
*   它会保留你与某个角色的聊天历史，让你可以随时继续、开始新聊天、查看旧聊天等。
*   在后台，它会为你做必要的准备工作来生成 AI 提示。具体来说，它会发送一个系统提示（给 AI 的指令），引导 AI 遵循某些规则以提高回复准确性。

## 概述一下我的 AI 模型选项

SillyTavern 可以与两种类型的 AI 交互：

1.  [Web 服务](/usage/api-connections/openai/)（基于云端，通常付费、专有、封闭）
2.  [自托管](/usage/how-to-use-a-self-hosted-model/)（本地、免费、开源）

### 付费 Web 服务 AI

付费的云端模型是黑盒。你向一家公司付费使用他们的 AI 服务。你在 SillyTavern 中填入账户信息，它会代表你连接到你的提供商来使用 AI。

优点：

*   上手非常容易。
*   质量最高的 AI 写作。

缺点：

*   使用需要花费金钱。
*   所有内容都会记录在他们的服务器上。存在隐私问题。
*   它们通常受到审查，会拒绝与你讨论某些主题。

### 自托管 AI

自托管模型是可以在你个人电脑上运行的免费模型，但需要一台性能强劲的电脑和更多的配置工作。

优点：

*   一旦配置好，即使没有网络连接也可以免费使用。
*   完全隐私。你写的所有内容都保存在你自己的电脑上。
*   模型种类丰富。作为一种社区驱动的技术，你可以找到适合你所需特定任务或行为的模型。

缺点：

*   它们的能力不如 <abbr title="最先进的">SOTA</abbr> 模型（例如，它们写出的对话质量较差，创造性较低等等）。
*   运行本地模型需要至少 6GB 显存的 GPU。

如果你有兴趣使用这些，请参考这里专门的指南：[如何使用自托管模型](/usage/how-to-use-a-self-hosted-model/)。

## 我能在手机或平板电脑上使用 SillyTavern 吗？

iPhone 和 iPad 无法运行完整的 SillyTavern 应用，但由于它只是一个 Web 界面，你可以将其在你家庭 Wi-Fi 网络中的另一台电脑上运行，然后在移动浏览器中访问它。有关更多信息，请参考[远程连接](/usage/remoteconnections/)。

对于 Android 用户，除了上述方法外，你还可以直接在你的手机上使用 Termux 应用运行完整的 SillyTavern，无需电脑。请参考[安装（Android）](/installation/android-(termux)/)。（注意：Termux 安装未得到官方支持，我们无法保证其能正常工作。）

## 我尝试导入 PNG 角色卡，但收到错误提示无效。为什么？

有两种可能性：

1.  卡片内部没有嵌入定义，只是一个普通的图像文件。某些程序或文件管理器会在你保存卡片时剥离嵌入的定义。请确保你使用的是原始 PNG 文件，即分享者发布时的版本。
2.  PNG 文件实际上是一个带有 `.png` 文件名的 WEBP 文件。你可以尝试在导入前将卡片重命名为 `.webp`，或者寻找该图像的合适 PNG 版本。

## 我如何制作自己的 AI 角色？

1.  点击角色管理按钮
2.  点击创建新角色
3.  在角色名称下，输入一个名字，比如 Amanda
4.  （可选）点击选择头像按钮，为此角色选择一张肖像图片
5.  在描述下，描述这个角色，并包含你认为与聊天相关的任何信息。例如：```Amanda 是一个在间隔年旅行的学生。她身高 6 英尺，是一名排球运动员。她拥有运动员般的身材。她有一头长长的棕色头发。她喜欢维多利亚时代的英格兰，并喜欢观看和阅读与此相关的电视和小说。```
例如，如果你希望 Amanda 友好，那么你可以添加：```Amanda 非常开朗和外向。```
6.  在首条消息下，编写当你开始新聊天时角色的问候语。例如：```*Amanda 向你挥手* 嘿！你也是个背包客吗？```
7.  点击创建角色按钮

现在你就有了一个可以进行聊天的基本角色。从角色列表中选择 Amanda，新的聊天就会开始。

请注意，你可以使用描述和/或首条消息来创建更具体的场景，并/或在描述中包含你自己。例如：

```txt
描述：
Amanda 是一个在间隔年旅行的学生。她身高 6 英尺，是一名排球运动员。她拥有运动员般的身材。她有一头长长的棕色头发。她喜欢维多利亚时代的英格兰，并喜欢观看和阅读与此相关的电视和小说。她一直保守着一个沉重的秘密，等待合适的人倾诉，但这可能导致与一个强大的秘密组织展开猫鼠游戏。她最近抵达了加尔各答。

你是 Rajesh Nahasmapetilon，一位世界著名的印度排球巨星。你在加尔各答散步。Amanda 发现你后兴奋地尖叫起来。

首条消息：
*Amanda 跑到你面前，满脸笑容。* Rajesh！我简直不敢相信！我是你的超级粉丝。我卧室里贴着你的海报。
```

你包含的任何相关信息都会被使用。使用效果取决于 AI 模型的能力水平。

注意：角色创建后，你可以返回并编辑除名称外的任何信息。

## 我的 API 密钥存储在哪里？为什么我看不到它们？

SillyTavern 将你的 API 密钥保存在用户数据目录下的 `secrets.json` 文件中（默认路径为 `/data/default-user/secrets.json`）。

默认情况下，在你保存密钥并刷新页面后，API 密钥不会在界面上显示。

要启用密钥查看功能：

1.  在 `config.yaml` 文件中将 `allowKeysExposure` 的值设置为 `true`。
2.  重新启动 SillyTavern 服务器。
3.  点击 API 连接面板右下角的“查看隐藏的 API 密钥”链接。

## 性能提示

### 为什么 UI 这么慢/卡顿？

*   尝试在用户设置面板中启用无模糊效果（快速 UI）模式。
*   在 UI 主题设置中启用减少动画以移除装饰性动画。
*   确保你的浏览器正在使用硬件加速。
*   如果使用流式响应，请将流式 FPS 设置为较低的值（建议 10-15 FPS）。

### 我遇到了输入延迟。该怎么办？

性能下降，特别是输入延迟，最常见的原因是浏览器扩展。已知有问题的扩展包括：

*   iCloud 密码管理器
*   DeepL 翻译
*   基于 AI 的语法修正工具
*   各种广告拦截扩展

如果你遇到性能问题且无法确定原因，或者怀疑是 SillyTavern 本身的问题，请：

1.  [录制性能分析文件](https://developer.chrome.com/docs/devtools/performance/reference)
2.  将分析文件导出为 JSON 文件
3.  提交给开发团队进行分析

我们建议首先禁用所有浏览器扩展和第三方 SillyTavern 扩展进行测试，以隔离性能下降的来源。

### 当我导入大量角色时，应用变得很慢。为什么？

不幸的是，SillyTavern 并非为处理庞大的角色库而设计。你拥有的角色越多，加载角色列表所需的时间就越长。有证据表明，当你有超过 1000 个角色时，性能下降开始变得明显。

不过，你可以采取一些措施来缓解此问题：

**1. 使用懒加载。**

在 `config.yaml` 文件中将 `performance.lazyLoadCharacters` 设置为 `true` 来启用角色懒加载。下次服务器重启后，角色列表将只加载你与之交互的角色的完整数据。请注意，某些第三方扩展如果未更新以支持此设置，可能无法正常工作（请联系扩展开发者了解更多信息）。

**2. 使用内存缓存。**

如果你有多余的 RAM，可以增加内存缓存容量。这将允许服务器在内存中保留更多角色，减少加载它们所需的时间。你可以通过在 `config.yaml` 文件中将 `performance.memoryCacheCapacity` 的值调整为更大的数字来实现。默认值为 `100mb`。大致经验法则：每拥有 3000 个角色，将值增加 100mb。

**限制：**

1.  启用懒加载后，高级（模糊）角色搜索将无法使用。只能搜索角色名称。
2.  由于可用内存有限，Android 设备上禁用内存缓存。

## 如何让 AI 写更多内容？

有时 AI 只回复一句话，而你希望它更详细。
这通常是本地运行模型的问题。

如果你只是想让机器人从它最近一次回复的结尾处继续写下去，你可以在输入栏中不输入任何内容，然后点击发送来发送一条空用户消息。这将强制机器人继续故事。

修复策略：

*   增加`响应长度`设置的值
*   为角色设计一个良好的`首条消息`，展示其长篇大论的说话风格。在给出你所期望的写作风格指导时，AI 模型可以有很大提升。
*   在角色的描述框中添加诸如“喜欢说很多话”或“非常健谈”之类的短语
*   在`作者注`或`历史后指令提示`中做同样的事情
*   作为最后的手段，你可以尝试开启`自动继续`（在用户设置面板中），但这会使响应速度变慢，因为它会让 AI 连续生成小的回复，然后将它们全部合并成一个大的回复。它也可能与某些 API 选项不兼容。

## 如何让 AI 写更少内容？

这主要是 ChatGPT 或 Claude 等模型的问题。相同的策略可以反向应用。

*   减小`响应长度`设置的值
*   在角色的描述中给出类似“话少”或“不太说话”的短语。
*   给角色一个简短的首条消息，为聊天设定基调和期望。
*   确保`自动继续`已关闭。

## 如何让 AI 停止编写我角色的动作并独自推动剧情？

这应该通过 `作者注` 使用以下短语组合来处理：

*   \{\{char\}\} 的回应只能是被动的，并且对 \{\{user\}\} 的动作做出反应。
*   你的下一个回应必须仅从 \{\{char\}\} 的视角出发。
*   你不得为 \{\{user\}\} 指定动作或发言。
