## 通用设置

这些是影响您整体 SillyTavern 体验的核心设置。

### UI 语言

SillyTavern 的用户界面支持多种语言。语言选择器提供以下选项：
* **默认**：如果可用，使用您的系统语言。
* **英文**：忽略系统设置，强制使用英文界面。
* 通过下拉菜单选择其他语言。

注意：此设置仅影响用户界面文本。如需 AI 对话翻译，请使用聊天翻译扩展。

### 软件版本

您当前的 SillyTavern 版本显示在右上角。此信息对于以下方面至关重要：
* 故障排查
* 确保与扩展的兼容性
* 确定是否有可用更新

要将 SillyTavern 更新到最新版本，请参考[更新](/installation/updating/)文档。

### 账户管理

控制您的 SillyTavern 用户账户，备份您的设置和用户数据，并在[多用户模式](/administration/multi-user/)中管理用户角色和权限。

#### <i class="fa-fw fa-solid fa-user-shield"></i> 账户

在账户对话框中，您可以查看和编辑您的个人信息、更改密码以及管理账户设置。

**个人信息**

* 显示名称（可通过铅笔图标编辑）
* 用户头像（也可通过[角色形象](/usage/core-concepts/personas/)更改）
* 账户句柄（Account handle）
* 用户角色
* 账户创建日期
* 密码状态（锁定/解锁图标表示保护状态）

**账户操作**

* **设置快照**：创建、管理和恢复用户设置的备份
* **下载备份**：导出所有用户数据的完整备份
* **更改密码**：更新您的账户安全凭据

**危险区域**

需要谨慎使用的关键账户操作：
* **重置设置**：将所有设置恢复为出厂默认值
* **重置所有**：完全清除账户并恢复出厂设置

## 角色处理

* **角色列表副标题**：选择在 [<i class="fa-fw fa-solid fa-address-card" title="角色图标"></i> 角色](/usage/core-concepts/characterdesign/)列表中的角色名称下显示哪些额外信息：
    - 角色版本
    - 创建者
* **导入卡片标签**：控制导入角色卡片时如何处理标签：
    - 询问 - 每次导入时显示对话框
    - 无 - 不导入任何标签
    - 所有 - 导入所有标签
    - 已存在 - 仅导入已存在的标签
* **高级角色搜索**：启用后，使用模糊匹配并搜索所有角色数据字段，而不仅仅是名称。
* **优先使用角色提示**：启用后，在可用时使用角色卡片的系统提示覆盖。
* **优先使用角色指令**：启用后，在可用时使用角色卡片的对话后指令覆盖。
* **从不调整头像大小**：防止裁剪/调整导入的角色图像大小。禁用时，图像会被调整为 512x768。
* **显示头像文件名**：在角色列表中显示角色头像的实际文件名。
* **无剧透模式**：在编辑器面板中，将角色定义隐藏在剧透按钮之后。

## 杂项

* **重新加载聊天**：重新加载并重绘当前聊天。
* **[调试菜单](#debug-menu)**：访问调试选项。

* **流式淡入**：对流式文本应用淡入效果。可与平滑流式输出同时使用，也可单独使用。
* **[消息音效](/usage/core-concepts/uicustomization/#message-sound)**：消息生成完成时播放音效。
    - **仅后台音效**：仅当浏览器标签页未聚焦时播放音效。
* **宽松的 API URL**：降低 API URL 的格式要求。
* **知识库导入对话框**：在导入包含嵌入式知识库的角色时，显示世界信息/知识库导入对话框。
* **自动选择输入文本**：点击某些输入字段时自动选中其中的文本。
* **Markdown 快捷键**：启用 Markdown 格式的键盘快捷键。
* **恢复用户输入**：页面刷新时保留未保存的用户输入。
* **移动UI**：允许通过拖拽重新定位 UI 元素（仅限 PC）。
    - <i class="fa-solid fa-recycle" title="重置图标"></i> **重置**按钮用于恢复默认位置
    - 用于保存/加载 UI 布局的预设系统

## 聊天/消息处理

### 消息显示设置

控制消息在聊天界面中的加载和显示方式。这些设置会影响整体聊天体验和性能。
* **加载消息数**：分页前加载的聊天历史消息数量（0 = 全部）
* **流式 FPS**：流式文本的更新速度（5-100 FPS）
* **示例消息行为**：
    - 逐渐推出
    - 始终包含示例
    - 从不包含示例
* **图像滑动行为**（控制图库风格中图像的滑动操作）：
    - 生成新图：允许使用[图像生成](/extensions/stable-diffusion/)扩展生成新图像
    - 轮换：循环浏览现有图像，到达末尾时回绕

### 输入与响应控制

决定消息发送方式及 AI 如何继续其响应的设置。
* **回车发送**：可选择禁用、自动（PC）或启用
* **“发送”以继续**：使用发送按钮继续 AI 响应
* **快速“继续”按钮**：显示用于扩展 AI 上一条消息的按钮
* **快速“冒充”按钮**：显示用于单条消息角色冒充的按钮
* **滑动**：显示用于选择替代 AI 响应的箭头按钮（PC 和移动端）
* **手势**：启用滑动手势以进行生成（仅限移动端）

### 自动管理

帮助管理聊天流程和内容的自动化功能。
* **自动加载上次聊天**：启动时自动加载最近的聊天
* **自动滚动聊天**：自动滚动到最新消息
* **自动保存消息编辑**：无需确认即可保存消息编辑
* **确认消息删除**：删除消息前提示确认
* **自动修复 Markdown**：自动纠正 Markdown 格式

#### 自动滑动

根据可配置条件自动拒绝并重新生成 AI 消息。
* **启用自动滑动**：自动滑动功能的总开关
* **最小生成消息长度**：如果消息短于此值，则触发自动滑动
* **黑名单词**：可触发自动滑动的词列表，用逗号分隔
* **触发滑动的黑名单词数量**：检测到的最小黑名单词数量，达到此数量即触发自动滑动

#### 自动继续

如果模型在达到特定长度之前停止，则自动继续生成响应。

这允许您的 AI 分多部分写出长响应，从而使您可以使用较短的[响应长度设置](/usage/common-settings/#response-tokens)，同时仍然获得较长的回复。

它不会让 AI 写出比原本更多的内容。要求 AI 继续一条它认为“已完成”的消息通常不起作用。请参阅[如何让 AI 写更多内容？](/usage/faq/#how-to-make-the-ai-write-more) 获取其他思路。

* **启用自动继续**：自动继续功能的总开关
* **允许聊天补全 API**：为聊天补全 API 端点启用自动继续功能
* **目标长度（tokens）**：期望的消息长度（以 token 计）——如果消息短于此值，将触发继续（0-1024）

### 消息格式与显示

控制消息的格式以及显示哪些内容。
* **禁止外部媒体**：阻止来自外部域的嵌入媒体
* **在响应中显示 {\{char}}:** ：如果生成，则保留响应中的角色名称前缀
* **在响应中显示 {\{user}}:** ：如果生成，则保留响应中的用户名称前缀
* **实验性宏引擎**：启用支持嵌套的高级宏处理
* **在响应中显示标签**：允许响应中的（某些）HTML 标签以 HTML 形式显示
* **放松群组消息修剪**：允许 AI 在群组聊天中为其他角色发言，而不是停止响应生成
* **显示群聊队列**：在群组聊天的角色列表中显示响应顺序
* **固定问候消息样式**：始终渲染问候语中的样式标签，即使消息因懒加载而未加载。

### 提示检查与调试

* **将提示记录到控制台**：将提示输出到浏览器控制台
* **请求 token 概率**：从 API 请求 AI 响应的 token 概率。如果可用，这些可以在 <i class="fa-solid fa-bars" title="汉堡菜单图标"></i> [Token 概率](/usage/chatting/#token-probabilities-panel) 中查看。

### 自动完成

- 自动隐藏详细信息
- 匹配样式（开头匹配/包含/模糊匹配）
- 视觉样式（主题/深色/浅色）

- 宽度控制

## 清理菜单

清理菜单提供了一种数据维护工具，可帮助您识别并删除 SillyTavern 安装中不必要的文件。此功能有助于保持数据目录整洁，并可能释放大量磁盘空间。

> **⚠️ 重要警告**
>
> 清理工具将永久删除文件。**此操作无法撤销！**
>
> 手动上传到 `/data/user/files/` 和 `/data/user/images/` 目录的文件，如果未与聊天消息或数据银行条目关联，则会被删除。
>
> 如有疑问，请在使用清理菜单前备份您的数据。


### 如何使用清理

1. 点击**杂项**部分下的**清理**按钮
2. 点击**扫描**以分析您的安装。根据数据目录的大小，这可能需要一些时间
3. 查看找到的文件类别
4. 使用**查看**在删除前预览文件内容
5. 使用**下载**在删除前保存文件
6. 根据需要删除单个文件或整个类别

### 清理类别

清理工具扫描松散文件，分为以下类别：

#### 文件

* **查找内容**：未与聊天消息或数据银行条目关联的文件
* **位置**：`/data/<用户句柄>/user/files/`
* **风险**：⚠️ **将删除未在聊天中引用的手动上传文件**
* **清理时机**：如果您不需要未引用的文件，则可以安全删除

#### 图片

* **查找内容**：未与聊天消息关联的图片
* **位置**：`/data/<用户句柄>/user/images/`
* **风险**：⚠️ **将删除未在聊天中引用的手动上传文件**
* **清理时机**：如果您不需要未引用的图片，则可以安全删除

#### 聊天

* **查找内容**：与已删除角色关联的聊天文件
* **位置**：`data/<用户句柄>/chats/`
* **风险**：⚠️ **孤立聊天将永久丢失**
* **清理时机**：如果您有意删除了角色且不再需要其聊天历史，则可以安全删除

#### 群聊

* **查找内容**：与已删除群组关联的聊天文件
* **位置**：`data/<用户句柄>/group chats/`
* **风险**：⚠️ **孤立群聊将永久丢失**
* **清理时机**：如果您有意删除了群组且不再需要其聊天历史，则可以安全删除

#### 头像缩略图

* **查找内容**：缺失或已删除角色的头像缩略图
* **位置**：`data/<用户句柄>/thumbnails/avatar`
* **风险**：✅ **可安全删除** - 缩略图在需要时会自动重新生成
* **清理时机**：始终可以安全清理，有助于释放空间

#### 背景缩略图

* **查找内容**：缺失或已删除背景的缩略图
* **位置**：`data/<用户句柄>/thumbnails/bg`
* **风险**：✅ **可安全删除** - 缩略图在需要时会自动重新生成
* **清理时机**：始终可以安全清理，有助于释放空间

#### 聊天备份

* **查找内容**：自动生成的聊天备份
* **位置**：`data/<用户句柄>/backups/chat_*`
* **风险**：⚠️ **备份文件将永久丢失**
* **清理时机**：建议保留最近的备份，但旧备份可以安全删除

#### 设置备份

* **查找内容**：自动生成的设置备份
* **位置**：`data/<用户句柄>/backups/settings_*`
* **风险**：⚠️ **设置备份文件将永久丢失**
* **清理时机**：建议保留最近的备份，但旧备份可以安全删除

## 调试菜单

> **⚠️ 这些功能仅供高级用户使用。**
>
>
> 除非您完全理解其后果，否则请勿使用。


调试菜单提供用于故障排查、维护和开发的功能。请谨慎使用这些功能，因为它们可能对您的 SillyTavern 安装产生重大影响。

由于扩展可以添加调试功能，因此可用选项将根据您安装的扩展而有所不同。

### 翻译与本地化功能
* **获取缺失的翻译**：分析当前语言环境（如果选择英文，则分析所有语言环境）中缺失的翻译，并将结果输出到浏览器控制台
* **应用语言环境**：通过重新应用所选语言环境来强制刷新当前语言设置
### 缓存与存储管理
* **清除 WebSearch 缓存**：从本地缓存中删除所有存储的搜索结果
* **清空所有向量索引**：完全移除所有来源中存储的所有向量
* **重置 token 缓存**：清除存储的 token 计数，强制对所有聊天进行完整的重新 token 化
* **删除逐项提示**：从本地存储中删除所有逐项提示
### 数据与统计
* **刷新统计文件**：使用现有聊天数据重建统计文件
* **回填 token 计数器**：重新计算当前聊天中所有消息的 token 计数
    - 在具有不同 token 化器的模型之间切换时有用
    - 完成后会触发聊天重新加载
    - 仅更改显示，不修改聊天内容
### API 与扩展测试
* **更改 Mancer 基础 URL**：修改 Mancer API 服务器的基础 URL
* **测试 WebSearch 扩展**：使用当前设置执行测试搜索
* **发送生成请求**：使用当前选择的 API 测试文本生成
### 系统与调试工具
* **强制引导**：重新启动引导过程
* **切换事件追踪**：启用/禁用用于调试的事件跟踪
* **复制 ST 设置**：[工作进展中] 将系统配置数据复制到剪贴板，用于错误报告

每个函数都可以通过其描述下方的“执行”按钮来运行。建议在使用这些工具前备份数据，因为某些操作无法撤销。
